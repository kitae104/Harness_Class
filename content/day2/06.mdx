## 이번 시간에 할 일

지난 시간에 쓴 설계서를 실제로 동작하는 **내 업무 Project**로 옮깁니다.
설계서의 지침 칸은 지침 문장으로 직접 써서 지침란에 넣고, 근거 칸의 파일은 Project 파일로 올립니다.
마지막으로 평가 5문항을 D1-6과 같은 방법으로 실행해 첫 점수를 잽니다.

## 필수 경로

1. 설계서의 지침·안전장치 칸을 보고 지침서 5항목을 직접 쓰고, 막히면 카드로 설계서와 대조합니다.
2. 내 업무 Project를 만들어 지침을 지침란에 저장하고, 지침 버전에 v1으로 적습니다.
3. 키트의 근거 파일(규정·양식)만 Project 파일로 올리고, 자료 목록에 적습니다.
4. 평가 5문항을 Project 새 대화에 질문만 넣어 답을 받습니다.
5. Project 밖 비개인화 임시 채팅에서 채점하고, 3문항을 직접 확인해 점수를 기록합니다.

## 지난 시간에서 이어가기

D2-5에서 하네스 설계서 v1과 평가 10문항을 정했습니다. 기대 답변은 내 파일에만 두었습니다.
설계서는 계획입니다. AI는 설계서를 읽지 않고, 지침란과 Project 파일만 봅니다.
오늘은 계획을 실제 환경으로 옮기고, 정해 둔 문항으로 잘 옮겨졌는지 잽니다.

## 설계 예시 — 설계서 칸이 들어가는 곳

민원 하네스에서 해 본 대로, 설계서의 칸마다 **담는 곳이 다릅니다.** 한 곳에 모두 붙이지 않습니다.

| ① 지침 | Project 지침란(지침서 5항목 + 출처 규칙) | 채팅창 |

| ③ 도구 | 채팅 첨부(입력 자료가 있는 예시), 선택: 업무용 폼 | Project 파일 |
| ④ 검증 | 내 평가 파일(Project 밖), 하네스 대장 평가 표 | Project 파일, Project 대화 |
| ⑤ 안전장치 | 지침의 금지사항·모를 때 행동, 출력의 "초안·검토 필요" 표시 | — |
| ⑥ 기록 | 하네스 대장(지침 버전, 자료 목록, 평가) | — |

## 실습 — 지침 쓰고 Project 만들기

이번에는 지침을 **직접 씁니다.** D1-2에서 따라 쓰고, D2-4에서 바꿔 써 본 기술의 세 번째입니다.

**지침 초안을 씁니다.** 메모장에 씁니다.

1. 키트의 지침서 틀을 복사해 엽니다. 틀의 다섯 제목(역할, 범위, 금지사항, 출력 형식, 모를 때 행동)을 그대로 둡니다.
2. 설계서 ① 지침 칸을 보고 항목마다 문장을 씁니다. 대괄호 질문에 모두 답합니다.
3. 설계서 ⑤ 안전장치 칸의 개인정보 규칙과 숨은 지시문 규칙을 금지사항에 옮깁니다.
4. 출처 규칙을 맨 아래에 더합니다. D1-4의 출처 규칙 카드와 같은 모양으로, 자료 이름과 연락처만 바꿉니다.
5. 기한·금액·서류 목록 같은 **사실은 적지 않습니다.** 사실은 근거 파일에 있고, 지침에는 행동 규칙만 둡니다.

**Project를 만듭니다.** 만드는 순서는 D1-3과 같습니다. **Project**는 <Feature id="chatgpt-projects" />입니다.

1. 새 Project를 만들고 이름을 "내 업무 — (업무 이름)"으로 합니다. 민원 비서 Project와 섞지 않습니다.
2. 지침 초안 전문을 **지침란**에 붙여 넣고 저장합니다. 채팅창에 붙이지 않습니다.
3. 하네스 대장 지침 버전에 지침 전문을 붙이고, 버전 "v1", 바꾼 이유 "설계서 v1에서 옮김"을 적습니다.

## AI 도움받기 — 설계서를 지침으로 옮기기

지침 초안을 지침란에 넣기 전에, 설계서와 빠짐없이 맞는지 대조할 때 씁니다.
이 카드는 **직접 쓰기** 단계입니다. 5칸 뼈대만 보고 요청을 직접 씁니다. 막히면 힌트 보기(바꿔 쓰기)나 전체 보기(따라 쓰기)를 펼칩니다.
Project 밖 **새 채팅**에 붙여 넣습니다. 지침란에 넣기 전의 점검이기 때문입니다.

<PromptCard id="card-design-to-guideline" />

AI가 짚은 곳을 **내가 직접** 고칩니다. AI가 새 문장을 써 주면 옮기지 않고 다시 요청합니다.

## 실습 — 키트 근거 자료 올리기

근거는 **규정과 양식만** Project 파일로 올립니다. 키트의 다른 파일은 역할이 다릅니다.

## 실습 — (선택) 업무용 폼 사본 고치기

업무용 폼은 **선택**입니다. 시간이 남거나, 폼 문항 틀이 있는 예시(현장 점검, 수요조사)를 고른 경우에만 합니다.
폼을 만들지 않아도 설계서 ③ 도구 칸은 그대로 둡니다. 도구는 폼이 아니라 흐름입니다.

1. 강사가 나눠 준 폼 사본 링크가 있으면 사본을 만듭니다. 없으면 키트의 폼 문항 틀을 보고 D2-1처럼 새로 만듭니다.
2. 내 업무에 맞게 문항 한두 개를 고칩니다. 이름·연락처처럼 필요 없는 개인정보 문항은 넣지 않습니다.
3. 설정에서 이메일 수집을 끕니다. 사진 문항이 있으면 선택으로 둡니다.
4. 설계서 ③ 도구 칸에 폼 이름과 응답이 쌓이는 시트를 한 줄 더합니다.

## 실습 — 평가 5문항 실행과 기록

지난 시간에 정한 평가 문항 중 **1~5번**으로 첫 점수를 잽니다. 키트 후보의 1~5번에는 네 유형이 모두 들어 있습니다.
재는 방법은 **D1-6과 같습니다.** 답변과 채점을 나누고, 사람이 표본을 확인합니다. 자세한 순서는 [D1-6 페이지](/course/day1/06/)를 봅니다.

**1. 평가 전 준비**

1. Project 파일 목록에 근거 파일만 있는지 다시 봅니다.
2. 지침을 시험하느라 연 연습 대화가 있으면 지웁니다. 지우는 위치는 D1-6과 같습니다.
3. 기대 답변 파일은 채점할 때만 Project 밖에서 연다는 것을 확인합니다.

연습 대화가 평가 답에 영향을 주는지는 아직 확인 중입니다. <Feature id="chatgpt-project-memory-eval-impact" /> 확인될 때까지 영향이 있다고 보고 정리합니다.

**2. 답변 받기**

1. 내 업무 Project에서 **새 대화**를 엽니다.
2. 입력 자료가 있는 예시는 입력 파일을 이 대화에 **첨부**합니다.
3. 내 평가 질문 파일의 1~5번을 **질문만** 붙여 넣고 보냅니다. 기대 답변은 넣지 않습니다.
4. 5번까지 모두 답했는지 번호를 세고, 받은 답 전체를 메모장에 붙여 둡니다.

**3. 채점하기** — 아래 채점 카드를 Project 밖 **비개인화 임시 채팅**에 붙여 넣습니다. <Feature id="chatgpt-temporary-chat" />

1. 카드의 힌트 보기(바꿔 쓰기) 문구를 복사하고, [업무 이름]을 내 업무 이름으로 바꿉니다.
2. [질문과 기대 답변]에 내 기대 답변 파일의 1~5번을, [받은 답]에 받은 답 전체를 붙여 넣고 보냅니다.

## AI 도움받기 — 결과가 이상할 때

답이 지침의 형식을 따르지 않거나, 올린 자료와 다른 말을 하면 씁니다. 지침·근거·입력 중 어디가 문제인지 좁힙니다.
이상한 답이 나온 **그 Project 대화**에 붙여 넣습니다. 평가 중이라면 채점과 기록을 마친 뒤에 씁니다. 기대 답변은 넣지 않습니다.

지침을 넣고 Project 파일에 키트 폴더의 파일을 **모두** 올렸습니다. 평가 질문과 기대 답변 파일도 함께 올라갔습니다.
평가를 돌리자 다섯 문항 모두 기대 답변과 거의 같은 문장으로 답했고, 채점은 5점 만점이었습니다.

**어디가 왜 틀렸나**

- **정답을 보고 답했습니다**: 기대 답변 파일이 Project 파일에 있어, 비서가 그 파일을 근거로 삼았습니다. 실력이 아니라 정답을 옮긴 점수입니다.
- **점수로 고칠 곳을 찾을 수 없습니다**: 첫 평가가 만점이면 지침의 빈틈을 알려 주는 신호가 사라집니다. 다음 시간에 개선할 문항이 없습니다.
- **근거와 평가가 섞였습니다**: 지침서 틀과 평가 질문도 근거가 아닙니다. 답 끝의 "근거:"에 평가 파일 이름이 나오면 섞였다는 표시입니다.

## Harness에서 무엇을 바꿨는가

설계서 한 장이 **동작하는 하네스**가 되었습니다. 지침(Instructions)은 지침란에, 근거(Context)는 Project 파일에 담았습니다.
입력 자료는 채팅에 첨부해, 근거와 입력을 섞지 않는 **도구(Tools)** 의 흐름을 지켰습니다.
평가 5문항으로 첫 점수를 얻어 **검증(Evals)** 이 시작되었고, 지침 버전·자료 목록·평가 표로 **기록(Observability)** 을 남겼습니다.
