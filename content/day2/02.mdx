## 이번 시간에 할 일

모인 민원 여러 건을 민원 답변 비서에게 한 번에 분류·요약시킵니다.
보내기 전에 표 안의 개인정보부터 찾아 지웁니다. 분류 기준표는 Project 파일로, 민원 표는 채팅 첨부로 넣습니다.
AI가 "확인 필요"로 표시한 건은 사람이 기준표로 다시 보고, 결과를 시트에 붙여 분류 대장을 만듭니다.

## 필수 경로

1. 민원 표 파일(CSV)을 열어 이름·상세 주소가 든 칸을 찾아 지웁니다.
2. 분류 기준표를 Project 파일로 올리고, 강사 시연에서 표 파일을 채팅에 첨부하는 법을 봅니다.
3. Project 새 대화에 표 파일을 첨부하고, AI에게 도움받기 카드로 분류를 요청합니다.
4. "확인 필요" 건을 기준표와 대조해 검토합니다.
5. 결과 표를 분류 대장에 붙이고, 카드의 반복 규칙을 지침으로 옮깁니다.

## 지난 시간에서 이어가기

D2-1에서 민원 접수 폼을 만들고, 강사 공용 폼에 가상 민원을 응답했습니다. 민원이 표 한 장에 모였습니다.
오늘은 그 표를 Day 1의 민원 답변 비서 Project v3에 넘깁니다. 새 비서를 만들지 않습니다.
지침과 근거는 그대로 두고, 여러 건을 처리하는 흐름 하나를 더합니다.

AI에게 주는 자료는 두 가지입니다. 두 가지를 넣는 곳이 다릅니다.

- **입력 데이터**: 이번에 처리할 대상입니다. 오늘의 민원 표 파일(CSV)입니다. **채팅에 첨부**해 그 대화에서만 씁니다.
- **첨부 전 점검**: 입력 데이터는 밖에서 들어온 자료입니다. 보내기 전에 개인정보가 섞였는지 사람이 먼저 봅니다.

담당자 책상의 업무 편람과 오늘 들어온 접수 서류철과 같습니다. 편람은 늘 책상에 두고, 서류철은 처리하고 넘깁니다.
민원 표를 Project 파일로 올리면, 다음 대화에서 AI가 민원 내용을 근거처럼 참고할 수 있습니다.

## 실습 — 확인 필요 건 검토

AI는 판단할 수 없는 건에 "확인 필요"를 표시합니다. 그 표시가 맞는지는 사람이 기준표로 봅니다.
분류 기준표를 열어 3절 "확인 필요 판단 기준"을 옆에 둡니다.

**이렇게 검토합니다.**

1. 결과 표에서 확인 필요가 "예"인 건을 직접 셉니다. 표 아래 "확인 필요 N건"과 같은지 봅니다.
2. "예"인 건마다 이유 기호(A~E)의 기준 문장을 읽고, 그 민원에 맞는지 봅니다.
3. "아니오"인 건 중에서 두 가지를 찾습니다. 내용이 한 줄뿐인 건, 전화·문자 회신인데 연락처가 빈 건입니다.
4. AI 판단과 내 판단이 다른 건은 번호와 이유를 메모장에 한 줄씩 적어 둡니다.

## 기록 — 분류 대장

AI의 결과는 대화에만 두면 사라집니다. 시트에 붙여 **분류 대장**으로 쌓습니다.
분류 대장은 분류 결과를 한 건에 한 줄씩 쌓아 두는 표입니다. D2-3에서 이 대장의 번호로 초안과 검토 기록을 이어 봅니다.

<ExternalLink id="sheet-harness-ledger" tab="classification" />

**이렇게 붙입니다.**

1. 하네스 대장에 "분류 대장" 탭을 만들고 위 머리행을 붙입니다.
2. AI가 만든 결과 표를 복사해 머리행 아래 첫 칸에 붙입니다.
3. 검토에서 메모한 건은 그 건의 비고에 "사람 검토: " 뒤에 이유를 이어 적습니다.
4. 표 아래 빈 줄에 "확인 필요 N건"을 적습니다. N은 내가 직접 센 수입니다.

## 되돌아보기 — 카드를 지침으로 옮기기

방금 쓴 카드는 깁니다. 그런데 역할, 규칙, 출력 형식은 다음 분류 때도 한 글자도 바뀌지 않습니다.
매번 같은 규칙을 붙이는 것은 하네스가 아닙니다. 반복되는 규칙은 **지침**에, 기준은 **근거**에 둡니다.
그러면 요청은 "무엇을 처리할지"만 남아 한 줄로 짧아집니다.

**이렇게 옮깁니다.**

1. 지침란의 지금 지침 전문을 하네스 대장 지침 버전에 복사합니다. 바꾼 이유는 "D2-2 분류 규칙을 지침으로"입니다.
2. 아래 "여러 건 분류 규칙"을 지침란 맨 아래에 붙이고 저장합니다. 카드의 규칙과 출력 형식을 모은 것입니다.

## Harness에서 무엇을 바꿨는가

민원 비서에 여러 건을 한 번에 처리하는 **도구(Tools)** 흐름이 생겼습니다. 폼 → 시트 → 표 파일 첨부 → 분류 대장입니다.
분류 기준표를 Project 파일로 올려 **근거(Context)** 를 넓혔고, 민원 표는 채팅 첨부로 넣어 근거와 섞지 않았습니다.
첨부 전 개인정보 점검과 "확인 필요" 사람 검토는 **안전장치(Guardrails)**, 분류 대장과 개정 기록은 **기록(Observability)** 입니다.
카드의 반복 규칙을 **지침(Instructions)** 으로 옮겨, 요청은 짧아지고 규칙은 한 곳에서 관리됩니다.
