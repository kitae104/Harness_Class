# AI에게 도움받기 카드 — 틀린 문항의 원인 찾기(PROMPT_GUIDE 2~4절, PRACTICE_DESIGN 3절 실패 원인 3분류).
# 실패 분석 1회차라 기본 단계는 바꿔 쓰기(PRACTICE_DESIGN 5절). 붙여 넣는 곳은 Project 채팅이다.
# Project 안이어야 AI가 올린 자료와 지침을 보고 판별 질문에 답할 수 있다.
# 질문과 받은 답만 넣는다. 기대 답변과 채점할 때 적은 "틀린 이유"는 넣지 않는다 — 정답 내용이 Project 대화에 남으면 프로젝트 메모리로 재평가가 정답을 참조할 수 있다(CD-17). 재평가는 이 대화가 아니라 D1-6과 같은 방법으로 한다.
# AI는 원인을 분류할 뿐 정답이나 새 지침을 대신 쓰지 않는다. 고칠 곳은 수강생이 정한다.
