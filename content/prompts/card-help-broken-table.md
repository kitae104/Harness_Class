# AI에게 도움받기 카드 — 공통 문제 해결: 표가 깨질 때(TOOL_GUIDE 5·6절, PROMPT_GUIDE 2~4절).
# 공통 카드(lesson: common)라 특정 교시의 내용을 담지 않는다. 처음 만나는 문제라 기본 단계는 따라 쓰기.
# 붙여 넣는 곳은 표를 만든 그 Project 대화다. 새 대화를 열면 앞의 표를 다시 쓸 수 없다.
# 모양만 바꾸게 한다. 값·행 순서·열 순서를 바꾸면 결과를 믿을 수 없다.
# 시트의 메뉴 위치는 쓰지 않는다(제품 정보). 붙이는 방법은 강사 화면으로 안내한다.
