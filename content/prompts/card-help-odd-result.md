# AI에게 도움받기 카드 — 공통 문제 해결: 결과가 이상할 때 원인 찾기(TOOL_GUIDE 5·6절, PROMPT_GUIDE 2~4절).
# 공통 카드(lesson: common)라 특정 교시·업무의 내용을 담지 않는다. 처음 만나는 문제라 기본 단계는 따라 쓰기.
# 원인 후보는 TOOL_GUIDE 6절의 세 곳(지침·근거·입력)이다. 평가 채점의 실패 원인 3분류(PRACTICE_DESIGN 3절)와 겹치지 않게,
# 이 카드는 "답이 이상하게 나온 이유"를 AI가 무엇을 보고 답했는지로 되짚는 진단만 한다. 답을 고쳐 쓰지 않는다.
# 붙여 넣는 곳은 이상한 답이 나온 그 Project 대화다. 같은 대화여야 AI가 방금 본 지침·자료·입력을 되짚을 수 있다.
# 평가 중이라면 채점·기록을 마친 뒤에 쓰고, 기대 답변은 넣지 않는다(CD-17). 다시 평가하기 전에 이 대화를 정리한다(CD-22).
