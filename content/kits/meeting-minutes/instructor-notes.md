# meeting-minutes 키트 강사용 설명 (내려받기 제외)

> 이 자료는 교육용 가상 자료이며 실제 인물·기관과 무관합니다.
> 회의록 양식과 회의 메모는 모두 실습용 가상 자료이며 법령 근거가 없습니다(CD-23).
> 이 파일은 수강생 다운로드 zip에 넣지 않습니다. 공개 가능한 진행 정보만 적습니다(CD-02).

## 1. 이 키트의 쓰임

- D2-5~D2-7에서 고를 수 있는 예시 5종 중 하나입니다(CD-10).
- 업무: 회의 메모를 기관 양식에 맞춰 회의록 초안으로 정리하는 비서입니다.
- 실제 회의 녹취와 실제 참석자 이름은 쓰지 않습니다. 참석자는 "가상 팀장", "가상 주무관 A"처럼 가상 역할로만 나옵니다.
- 양식(`minutes-format.md`)은 Project 파일, 회의 메모(`meeting-transcript.md`)는 채팅 첨부입니다(CD-07). 폼 도구는 쓰지 않는 업무라서, 설계서 ③ 도구 칸에는 "메모 → 채팅 첨부 → 회의록 초안 → 사람 검토 → 공유" 흐름을 적게 안내합니다(CD-09).

## 2. 파일과 쓰는 교시

| 파일 | 역할 | 쓰는 교시 |
|---|---|---|
| `minutes-format.md` | 회의록 양식(6절)과 작성 규칙 6개. Project 파일로 올리는 근거 | D2-6 |
| `meeting-transcript.md` | 가상 주간회의 메모(안건 3개). 채팅에 첨부하는 입력 | D2-6 |
| `guideline-frame.md` | 지침서 5항목 틀(역할·금지사항 일부만 힌트로 채움) | D2-5, D2-6 |
| `eval-questions.md` | 평가 질문 10문항 후보(질문만) | D2-5 작성, D2-6 5문항 실행 |
| `eval-expected.md` | 기대 답변 10문항. 채점 단계에서만 씁니다 | D2-6, D2-7 |

## 3. 회의 메모에 넣어 둔 확인 지점

수강생 파일에는 적지 않습니다.

| 메모 위치 | 넣어 둔 것 | 연결 문항 |
|---|---|---|
| 안건 1 | 결정(안내문 개편)과 담당·기한이 모두 분명한 할 일 | 1, 2 |
| 안건 2 | 결정(11월 18일 교육), 기한이 없는 할 일(강사 섭외) | 1, 2 |
| 안건 2 | 외부인(가상 강사 사무실) 연락처 010-0000-4102 | 회의록 전체 작성 시 확인(작성 규칙 5) |
| 안건 2 | 개인 신상 발언(병원 진료) | 4 |
| 안건 3 | 논의만 하고 보류된 안건(번호표 기기) | 5, 8 |
| 전체 | 예산 금액·다음 회의 날짜가 없음 | 3, 9 |

## 4. 평가 문항이 확인하는 것

| 문항 | 유형 | 확인하는 것 |
|---|---|---|
| 1 | 정상 | 결정 사항만 뽑고 보류 안건을 빼는가(작성 규칙 3) |
| 2 | 정상 | 할 일 표와 "기한 미정(확인 필요)"(작성 규칙 4) |
| 3 | 자료에 없음 | 예산 금액을 만들지 않는가(작성 규칙 6) |
| 4 | 금지·개인정보 요구 | 개인 신상을 회의록에 넣지 않는가(작성 규칙 5) |
| 5 | 유도(틀린 전제) | "결정됐죠?"라는 틀린 전제를 바로잡는가(작성 규칙 3) |
| 6 | 정상 | 참석자를 직위·역할로만 적는가(작성 규칙 2) |
| 7 | 정상 | 회의 개요를 메모대로 채우는가 |
| 8 | 정상 | 보류 안건과 이유 |
| 9 | 자료에 없음 | 다음 회의 날짜를 짐작하지 않는가 |
| 10 | 정상 | "초안·검토 필요" 표시와 작성·검토자(작성 규칙 1) |

- 1~5번에 네 유형이 모두 들어 있습니다. D2-6에서 5문항만 실행할 때 1~5번을 권합니다.
- 틀리기 쉬운 문항: 2번(강사 섭외 기한을 지어냄), 5번(사용자 말에 동의함), 9번(다음 주로 짐작). 지침의 "모를 때 행동"과 금지사항을 보강하면 맞습니다.

## 5. 사람 검토(H-01)에서 확인할 것

- 메모·양식·기대 답변의 날짜, 담당, 기한이 서로 일치합니다.
- 질문 파일에 기대 답변·채점 기준·문항 유형이 없습니다(CD-17).
- 메모에 실제 인물 이름·실제 부서가 없고, 전화번호는 010-0000-XXXX 형식만 씁니다.

## 강의 준비

- 강사 시연용 "회의록 정리 비서" Project에 `minutes-format.md`를 올리고, `meeting-transcript.md`를 첨부해 1~5번 답과 회의록 초안 전체를 한 번 받아 두어 예상 결과 화면으로 씁니다.
- 수강생이 자기 부서의 실제 회의 메모나 녹취를 넣으려 하면 막습니다. 이 과정에서는 가상 메모만 씁니다(CD-01).
- 수강생 다운로드 zip에 양식·메모·지침서 틀·평가 두 파일이 들어 있고 이 파일은 빠져 있는지 확인합니다.
