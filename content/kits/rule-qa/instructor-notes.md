# rule-qa 키트 강사용 설명 (내려받기 제외)

> 이 자료는 교육용 가상 자료이며 실제 인물·기관과 무관합니다.
> 누리시 복무 규정은 실제 법령 원문이 아니며 법적 효력이 없는 실습용 합성 자료입니다(CD-23).
> 이 파일은 수강생 다운로드 zip에 넣지 않습니다. 공개 가능한 진행 정보만 적습니다(CD-02).

## 1. 이 키트의 쓰임

- D2-5~D2-7에서 "내 업무" 대신 고를 수 있는 예시 5종 중 하나입니다(CD-10).
- 업무: 직원의 인사·복무 문의(근무시간·연가·병가)에 규정 근거를 붙여 답하는 비서입니다.
- 국가직·지방직으로 나누지 않습니다(CD-12). 평가 문항은 두 직군 공통 주제(근무시간·연가·병가)에 맞췄고, 기관별 세부는 "소속 기관 규정 확인 필요"가 정답인 문항으로 넣었습니다.
- 실제 업무에서 확인할 법령은 교시 본문에서만 인용합니다. 이 키트의 규정은 가상 규정입니다(CD-23).

## 2. 파일과 쓰는 교시

| 파일 | 역할 | 쓰는 교시 |
|---|---|---|
| `rule-service.md` | 교육용 가상 복무 규정(제1조~제9조). Project 파일로 올리는 근거 | D2-6 |
| `guideline-frame.md` | 지침서 5항목 틀(역할·모를 때 행동만 힌트로 채움) | D2-5, D2-6 |
| `eval-questions.md` | 평가 질문 10문항 후보(질문만) | D2-5 작성, D2-6 5문항 실행 |
| `eval-expected.md` | 기대 답변 10문항. 채점 단계에서만 씁니다 | D2-6, D2-7 |

## 3. 평가 문항이 확인하는 것

| 문항 | 유형 | 확인하는 것 |
|---|---|---|
| 1 | 정상 | 근무시간 기본 안내(제3조) |
| 2 | 정상 | 반일 연가(제6조 제3항) |
| 3 | 자료에 없음 | 수당 금액을 짐작하지 않는가(제4조 제3항) |
| 4 | 금지·개인정보 요구 | 다른 직원의 건강정보를 알려 주지 않는가(제8조) |
| 5 | 유도(틀린 전제) | 틀린 전제("진단서 없이 30일")를 바로잡는가(제7조) |
| 6 | 정상 | 재직기간별 연가 일수(제5조) |
| 7 | 정상 | 당일 연가 절차(제6조 제2항) |
| 8 | 정상 | 병가 일수와 진단서(제7조) |
| 9 | 자료에 없음(기관별 세부) | "소속 기관 규정 확인 필요"로 답하는가(제2조 제2항, 제9조 제2항) |
| 10 | 정상 | 휴일 근무 = 시간외근무 사전 승인(제3조 제3항, 제4조) |

- 1~5번에 네 유형이 모두 들어 있습니다. D2-6에서 5문항만 실행할 때 1~5번을 권합니다.
- 틀리기 쉬운 문항: 9번(본청 근무시간을 사업소에 그대로 적용), 3번(일반 지식으로 수당을 설명). 둘 다 지침의 범위·모를 때 행동 문장을 고치면 맞습니다.
- 의도된 결함은 두지 않았습니다. Day 2는 수강생이 쓴 지침의 빈틈이 오답의 원인이 됩니다.

## 4. 사람 검토(H-01)에서 확인할 것

- 규정·기대 답변의 근거 조문이 서로 일치합니다.
- 질문 파일에 기대 답변·채점 기준·문항 유형이 없습니다(CD-17).
- 모든 파일 첫머리에 교육용 가상 자료 표기가 있고, 실제 법령명·법령 번호·실제 기관명이 없습니다.
- 수당 금액 등 금액이 어디에도 없습니다. 전화번호는 010-0000-XXXX 형식만 씁니다.

## 강의 준비

- 강사 시연용 "규정 Q&A 비서" Project를 미리 만들어 `rule-service.md`를 올리고, 1~5번 답을 한 번 받아 두어 예상 결과 화면으로 씁니다.
- 수강생 다운로드 zip에 `rule-service.md`, `guideline-frame.md`, `eval-questions.md`, `eval-expected.md`가 들어 있고 이 파일은 빠져 있는지 확인합니다.
- 규정 파일을 올릴 수 없는 교육망이면 규정 본문을 입력창에 붙여 넣는 플랜 B를 안내합니다.
- 수강생이 실제 소속 기관 복무 규정을 올리려 하면 막습니다. 이 과정에서는 가상 규정만 씁니다(CD-01).
