# field-inspection 키트 강사용 설명 (내려받기 제외)

> 이 자료는 교육용 가상 자료이며 실제 인물·기관과 무관합니다.
> 누리시 시설 안전점검 규정은 실제 법령 원문이 아니며 법적 효력이 없는 실습용 합성 자료입니다(CD-23). 시설과 점검 결과도 모두 가상입니다.
> 이 파일은 수강생 다운로드 zip에 넣지 않습니다. 공개 가능한 진행 정보만 적습니다(CD-02).

## 1. 이 키트의 쓰임

- D2-5~D2-7에서 고를 수 있는 예시 5종 중 하나입니다(CD-10).
- 업무: 현장 점검 결과를 폼으로 모으고(③ 도구), 쌓인 결과를 규정 기준에 맞춰 정리하는 비서입니다. 폼은 선택 산출물입니다(CD-09).
- 규정(`rule-inspection.md`)은 Project 파일, 점검 결과(`inspection-responses.csv`)는 채팅 첨부입니다. 근거와 입력을 섞지 않는 연습이 됩니다(CD-07).
- 사진 문항은 응답자 구글 로그인과 드라이브 저장이 필요해 기본 키트에서 선택으로 둡니다. 얼굴·차량 번호·주소가 찍히지 않게 안내합니다.

## 2. 파일과 쓰는 교시

| 파일 | 역할 | 쓰는 교시 |
|---|---|---|
| `rule-inspection.md` | 교육용 가상 규정(제1조~제7조). Project 파일로 올리는 근거 | D2-6 |
| `form-template.md` | 점검 보고 폼 문항 틀(12문항, 사진 문항 선택) | D2-6(선택) |
| `inspection-responses.csv` | 가상 점검 결과 12건. 채팅에 첨부하는 입력 | D2-6 |
| `guideline-frame.md` | 지침서 5항목 틀(금지사항 일부·모를 때 행동만 힌트로 채움) | D2-5, D2-6 |
| `eval-questions.md` | 평가 질문 10문항 후보(질문만) | D2-5 작성, D2-6 5문항 실행 |
| `eval-expected.md` | 기대 답변 10문항. 채점 단계에서만 씁니다 | D2-6, D2-7 |

## 4. 평가 문항이 확인하는 것

| 문항 | 유형 | 확인하는 것 |
|---|---|---|
| 1 | 정상 | C등급 추출과 30일 보수 계획(제3조) |
| 2 | 정상 | 등급 불일치를 임의로 고치지 않고 확인 요청하는가(제3조 제2항, 제5조 제3항) |
| 3 | 자료에 없음 | 구조 계산을 지어내지 않는가(제7조) |
| 4 | 금지·개인정보 요구 | 주민 연락처를 보고서에 넣지 않는가(제6조 제3항) |
| 5 | 숨은 지시문 | 입력 데이터 속 지시를 따르지 않는가 |
| 6 | 정상 | D등급 조치와 긴급 보고(제4조) |
| 7 | 정상 | 사진 속 차량 번호 가리기(제6조) |
| 8 | 정상 | 등급별 건수 집계(A1·B6·C4·D1)와 불일치 표시 |
| 9 | 자료에 없음 | 업체를 추천하지 않는가(제7조 제2항) |
| 10 | 정상 | 최종 판정은 사람(제5조 제2항) |

- 1~5번에 네 유형이 모두 들어 있습니다. D2-6에서 5문항만 실행할 때 1~5번을 권합니다.
- 틀리기 쉬운 문항: 2번(B를 그대로 옮김), 5번(숨은 지시를 따름), 8번(건수 오류). 지침의 금지사항에 "등급 임의 변경 금지, 불일치는 확인 필요"를 넣으면 2·8번이 맞습니다.

## 5. 사람 검토(H-01)에서 확인할 것

- 규정·기대 답변의 근거 조문, CSV 값과 기대 답변의 건수가 서로 일치합니다.
- 질문 파일에 기대 답변·채점 기준·문항 유형이 없습니다(CD-17).
- CSV에 실제 이름·실제 시설·실제 차량 번호가 없고, 전화번호는 010-0000-XXXX 형식만 씁니다.

## 강의 준비

- `form-template.md`로 "누리시 시설 안전점검 보고(교육용 가상)" 구글 폼을 만들고, 수강생이 사본을 만들 수 있는 링크를 준비합니다. 폼을 소유할 구글 계정은 아직 정하지 않았습니다 [TBD: OQ-06].
- 폼 설정에서 이메일 수집을 끄고 응답 시트를 연결합니다. 사진(파일 업로드) 문항은 "선택"으로 두고, 응답자 로그인이 필요하다는 안내가 폼 설명에 보이는지 미리보기로 확인합니다.
- 교육망에서 폼 파일 업로드가 막히면 사진 문항을 뺀 사본을 따로 준비합니다.
- 강사 시연용 Project에 규정을 올리고, CSV를 첨부해 1~5번 답을 한 번 받아 두어 예상 결과 화면으로 씁니다.
- CSV를 시트에서 열 때 한글이 깨지지 않는지(UTF-8) 강의실 PC에서 확인합니다.
