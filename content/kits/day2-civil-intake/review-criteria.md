# 답변 초안 검토 기준 (교육용 가상 자료)

> 이 자료는 교육용 가상 자료이며 실제 인물·기관과 무관합니다.
> 전입신고 관련 조문은 「누리시 전입신고 안내 규정(교육용 가상 규정)」의 조문입니다. 실제 법령 원문이 아니며, 법적 효력이 없습니다.

## 이 파일을 쓰는 방법

D2-3에서 AI가 만든 답변 초안 5건을 사람이 검토할 때 씁니다. AI는 초안만 만들고, 판정과 발송은 사람이 합니다.

1. 하네스 대장의 **초안 검토 기록** 표에 초안을 만든 건의 분류 대장 번호를 한 줄씩 적습니다. 표에는 **검토** 열과 **검토 메모** 열이 있습니다.
2. 초안 한 건마다 아래 "먼저 보는 것" 4가지를 차례로 확인합니다.
3. 결과에 따라 검토 열에 **승인·수정·보류** 중 하나를 적습니다.
4. 수정·보류는 검토 메모에 이유를 한 줄로 적습니다. 예: `과태료 금액 단정 → 금액 문장 삭제`

이 파일은 Project 파일로 올리지 않습니다. 사람이 검토할 때 옆에 두고 보는 기준입니다.

## 먼저 보는 것 4가지

| 순서 | 확인할 것 | 이렇게 되어 있으면 통과 |
|---|---|---|
| 1 | "초안·검토 필요" 표시 | 초안 맨 위나 맨 아래에 "초안·검토 필요"가 적혀 있다 |
| 2 | 개인정보 | 이름, 상세 주소(동·호수, 번지), 주민등록번호, 연락처가 초안 본문에 옮겨지지 않았다. 민원인에게 개인정보를 더 묻지 않는다(규정 제9조 제2항) |
| 3 | 금지 위반 | 과태료 금액을 적거나 "과태료는 없다"고 단정하지 않는다(규정 제7조 제3항). 자료에 없는 내용을 지어내지 않는다 |
| 4 | 근거와 정확성 | 안내 내용이 규정·FAQ와 맞고 근거 조문이 적혀 있다. 자료에 없는 사항은 "확인이 필요합니다"와 담당 연락처로 안내한다(규정 제10조 제2항) |

## 판정 기준

| 판정 | 언제 | 다음 할 일 |
|---|---|---|
| 승인 | 4가지를 모두 통과했다 | 사람이 한 번 더 읽고 발송한다. 발송은 AI가 하지 않는다 |
| 수정 | 고치면 바로 쓸 수 있는 문제가 있다. 예: "초안·검토 필요" 표시가 없다, 근거 조문이 빠졌다, 말투가 딱딱하다, 과태료 금액 문장 하나만 지우면 된다, 옮겨 온 주소 한 줄만 지우면 된다 | 사람이 직접 고친 뒤 승인한다. 고친 내용을 검토 메모에 적는다 |
| 보류 | 담당자 확인 없이는 답할 수 없다. 예: 분류 대장에서 "확인 필요"였던 건, 안내 내용 자체가 규정과 다르다, 다른 사람의 개인정보를 알려 주는 초안, 금액·결과를 단정한 부분이 답의 중심이다 | 담당 부서에 넘기고 초안은 보내지 않는다. 보류 이유를 검토 메모에 적는다 |

## 꼭 수정 또는 보류로 판정하는 경우

아래에 해당하면 다른 부분이 좋아도 **승인하지 않습니다.**

- **과태료 금액을 단정한 초안** → 금액 문장만 지우면 되면 수정, 금액 안내가 답의 중심이면 보류. 과태료는 "부과 대상이 될 수 있고, 금액은 담당 부서에 확인"으로만 안내합니다(규정 제7조 제2항·제3항).
- **개인정보를 옮긴 초안** → 옮긴 부분만 지우면 되면 수정, 다른 사람의 개인정보를 알려 주는 내용이면 보류.
- **"초안·검토 필요" 표시가 없는 초안** → 수정(표시를 붙인 뒤 다시 확인).

## 검토 기록 예

| 번호 | 검토 | 검토 메모 |
|---|---|---|
| (예시) 1 | 승인 | 제3조 근거 맞음 |
| (예시) 2 | 수정 | 초안 표시 없음 → 추가 |
| (예시) 3 | 보류 | 자료에 없는 사항 → 민원팀 확인 |

위 예시는 형식 예시입니다. 실제 판정은 내가 받은 초안을 보고 적습니다.
