# 누리1동 민원 접수 폼 문항 (교육용 가상 자료)

> 이 자료는 교육용 가상 자료이며 실제 인물·기관과 무관합니다.
> 누리시와 누리1동 행정복지센터는 가상의 도시와 기관입니다. Day 1 민원 답변 비서의 앞단, "민원이 들어오는 입구"를 만듭니다.

## 이 파일을 쓰는 방법

D2-1에서 구글 폼을 **처음부터 만들기**로 열고, 아래 문항 5개를 순서대로 옮겨 적습니다.

1. 폼 제목에 `누리1동 민원 접수(교육용 가상)`를 적습니다.
2. 문항 1~5를 아래 표대로 만듭니다. 문항 이름은 **글자 그대로** 적습니다. 응답 시트의 열 이름이 되고, 제공 CSV(`civil-requests-30.csv`)의 열 이름과 같아야 D2-2에서 같은 방법으로 분류할 수 있습니다.
3. 미리보기로 응답자 화면을 확인합니다.
4. 설정에서 **이메일 수집을 끕니다.** 이 폼은 민원 내용을 받는 폼이지 응답자를 확인하는 폼이 아닙니다. 필요 없는 개인정보는 처음부터 받지 않습니다.
5. 응답 탭에서 응답 시트를 연결하고, 시트 공유 범위를 부서 내부로 둡니다.

응답 시트에는 구글 폼이 자동으로 넣는 `타임스탬프` 열이 맨 앞에 붙습니다. 제공 CSV에는 이 열이 없습니다. 분류할 때는 무시해도 됩니다.

## 폼 설명(폼 맨 위에 붙여 넣기)

```
누리1동 행정복지센터(교육용 가상) 민원 접수 폼입니다.
이름, 주민등록번호, 상세 주소는 적지 마세요. 필요하면 담당자가 따로 확인합니다.
연락처는 회신이 필요할 때만 적습니다.
```

## 문항

| 번호 | 문항 이름 | 문항 형식 | 필수 | 이 문항이 있는 이유 |
|---|---|---|---|---|
| 1 | 접수일 | 날짜 | 예 | 기한이 있는 민원(예: 전입신고 14일)의 긴급도를 판단하는 기준 날짜입니다. |
| 2 | 민원 유형 | 객관식 | 예 | 담당 부서를 나누는 첫 단서입니다. 선택지는 분류 기준표(`classification-table.md`)의 유형과 같습니다. |
| 3 | 내용 | 장문형 | 예 | 민원인이 원하는 것을 자기 말로 적습니다. 분류·요약·답변 초안의 재료입니다. |
| 4 | 희망 회신 방법 | 객관식 | 예 | 처리 결과를 어떻게 알려 줄지 정합니다. 연락처가 필요한지 판단하는 기준이 됩니다. |
| 5 | 연락처 | 단답형 | 아니오 | 전화·문자 회신을 원할 때만 받습니다. 받지 않아도 되는 정보는 필수로 만들지 않습니다. |

### 문항 2 — 민원 유형 선택지(6개)

선택지는 아래 글자 그대로 넣습니다. 분류 기준표의 "유형" 열과 한 글자도 다르지 않아야 합니다.

- 전입·전출 신고
- 증명서 발급
- 복지·지원 상담
- 생활 불편 신고
- 시설 이용·예약
- 기타 문의

### 문항 3 — 내용 안내 문구

```
무엇을 원하시는지 적어 주세요. 이름, 주민등록번호, 상세 주소는 적지 마세요.
```

### 문항 4 — 희망 회신 방법 선택지(4개)

- 전화
- 문자
- 방문
- 회신 필요 없음

### 문항 5 — 연락처 안내 문구

```
전화나 문자 회신을 원하실 때만 적어 주세요. (실습에서는 010-0000-XXXX 형식의 가상 번호만 씁니다)
```

## 넣지 않는 문항

아래 문항은 이 폼에 넣지 않습니다. 민원을 분류하고 답하는 데 필요하지 않기 때문입니다.

- 이메일 주소(설정에서 수집 끄기)
- 이름
- 주민등록번호, 생년월일
- 상세 주소(동·호수)

시간이 부족하면 문항 1·2·3 세 개로 줄여서 만듭니다. 문항 이름은 그대로 둡니다.
