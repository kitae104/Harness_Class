# 강사 안내 — Day 1 · 3교시 ChatGPT Project로 비서 만들기

공개 가능한 진행 안내만 적는다(CD-02). 활동별 시간은 course.yaml `d1-project`의 activities를 따른다.

## 준비
- 강사 화면에 D1-2에서 쓴 지침서 v1(예상 결과 예시)을 메모장으로 열어 둔다. 시연에서 지침란과 채팅창에 붙인다.
- D1-1 기준 질문 1번과 강사가 받아 둔 첫 답을 띄워 둔다. 전·후 비교 시연에 쓴다.
- 시연용 Project는 수업 전에 만들지 않는다. 만드는 과정 자체를 보여 준다.

## 시연 순서
1. "지침을 어디에 넣느냐가 오늘의 핵심"이라고 한 줄로 말하고 시작한다. Project는 지침과 근거를 담는 그릇이며, 하네스 요소 자체가 아니라는 것을 짚는다.
2. Project를 새로 만들고, 지침란을 열어 v1 전문을 붙여 넣고 저장한다. 메뉴 위치는 천천히 보여 준다.
3. 비교를 위해 Project 밖 일반 대화의 채팅창에 v1과 기준 질문 1번을 함께 붙인다. 답이 형식을 따르는 것을 보여 준다.
4. 그 대화를 닫고 새 대화에서 질문만 다시 묻는다. 지침이 사라진 것을 보여 준다(막힘 지점 sp-d1-03-a).
5. Project 안의 새 대화에서 같은 질문을 묻는다. 지침란의 지침이 새 대화에도 적용된 것을 보여 준다.
6. "매번 채팅에 붙이는 긴 지시는 하네스가 아니다. 지침은 지침란에 한 번만 둔다"고 정리한다.

## 실습 진행
- 질문 하나에 2분 정도 걸린다. 다섯 개를 한 번에 붙이지 않고 하나씩 묻게 한다.
- 비교표는 붙여 넣기 두 번과 "예/아니오" 판단 하나만 하게 한다. 답을 요약하게 하지 않는다.
- 비교 체크리스트 네 가지(형식·범위·모를 때·금지)를 먼저 보게 한다. 차이를 못 찾는 수강생에게는 "예상 결과"를 열어 1번 답과 견주게 한다(막힘 지점 sp-d1-03-b).
- 형식이 맞아도 금액을 단정한 답은 "아니오"로 적게 한다. "잘못된 결과 예시 — 형식만 좋아 보이는 답"을 함께 본다(막힘 지점 sp-d1-03-c).
- 답에 기한이나 조문이 나오면 "지금은 근거 자료가 없어 확인할 수 없다"고 짚는다. D1-4에서 근거를 연결한다고 예고한다.
- 마지막 한 문장은 빈칸 틀을 채우게 한다. 자유 서술로 길게 쓰지 않게 한다.

## 선택 활동 진행
- 빼보기 실험을 기본으로 권한다. 지운 항목을 지침 버전의 v1 전문으로 반드시 되돌리게 한다. D1-4는 v1 지침 위에 출처 규칙을 더한다.
- 프로젝트 복제 메뉴는 아직 확인 전이다 [TBD: OQ-02]. 복제 대신 지침 버전의 v1으로 되돌리게 한다.
- 동료 공유 연습에서는 **평가에 쓸 Project를 공유하지 않는다.** 공유 프로젝트는 프로젝트 전용 메모리를 쓰게 되어 D1-6 평가 조건이 달라질 수 있다 [AS-OF: chatgpt-project-sharing]. 지침 전문을 짝에게 건네고, 짝은 그 지침만 읽고 설명하게 한다.
- 실무에서 동료와 함께 쓰는 방법은 프로젝트 공유로 안내한다. 다른 공유 방식은 다루지 않는다(CD-20) [AS-OF: chatgpt-custom-gpt-creation].

## 흔한 오류
| 증상 | 대응 |
|---|---|
| 지침을 채팅창에 붙여 넣었다 | 지침란으로 옮겨 저장하게 한다. 새 대화에서 다시 묻게 한다 |
| 지침란에 v1 일부만 저장되었다 | 지침란을 다시 열어 다섯 항목이 모두 있는지 보게 한다 |
| 같은 대화에서 이어서 물어 비교한다 | 질문마다 Project 안의 새 대화를 열게 한다. 지침이 환경에 들어갔는지는 새 대화에서만 보인다 |
| 답이 길고 형식이 흐트러졌다 | 지침란의 출력 형식 항목이 저장되었는지 본다. 그래도 흐트러지면 D1-7 실패 분석 사례로 메모하게 한다 |
| 형식만 보고 모두 "예"로 표시한다 | 비교 체크리스트의 금지 항목을 다시 보게 한다 |
| 답의 조문을 맞는 근거로 믿는다 | 아직 근거 자료를 올리지 않았으므로 확인할 수 없다고 설명한다 |
| D1-1 기준 답 기록이 없다 | "전 답"을 비우고 "메모"에 "전 답 없음"이라고 적게 한다. 짝의 기록을 함께 보게 한다 |
| 지침에 실제 기관 이름이나 실제 전화번호가 있다 | 누리시와 010-0000-XXXX 형식의 가상 번호로 바꾸게 한다 |

## 시간이 부족할 때 생략
course.yaml `skip_if_short`와 같다.
- 동료 공유와 빼보기 실험(선택 활동)은 건너뛴다.
- 그래도 부족하면 시연 3·4단계(채팅창 비교)를 말로만 설명한다. 기준 질문 5개 비교와 한 문장 정리는 줄이지 않는다. 두 학습목표를 확인하는 활동이다.

## 다음 교시로 넘길 것
- 각자의 "민원 답변 비서" Project 지침란에 v1 전문이 있는지 확인한다. D1-4에서 이 Project(v1)에 근거 자료를 올린다.
- 빼보기 실험을 한 수강생의 지침란이 v1으로 되돌려졌는지 확인한다.
- 하네스 대장 적용 전·후 비교표가 채워졌는지 확인한다. D1-7에서 개선 전·후를 볼 때 다시 쓴다.
