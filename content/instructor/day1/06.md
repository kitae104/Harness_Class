# 강사 안내 — Day 1 · 6교시 일괄 평가 실행

공개 가능한 진행 안내만 적는다(CD-02). 활동별 시간은 course.yaml `d1-eval-run`의 activities를 따른다.
평가 절차는 PRACTICE_DESIGN 3절(CD-17)을 따른다: 답변은 Project 새 대화에 질문만, 채점은 Project 밖 비개인화 임시 채팅, 사람이 3문항 표본 확인.
의도된 결함과 연결된 문항은 키트의 강사용 설명(`instructor-notes.md`)을 본다. 수업 중 먼저 알리지 않는다.
같은 Project의 다른 대화가 평가에 주는 영향은 아직 확인 전이다 [TBD: OQ-03]. 확인 전까지 영향이 있다고 보고, 평가 전에 연습 대화를 정리한다(CD-22). "정리하면 영향이 없다"고 말하지 않는다.

## 준비
- 강사 화면에 민원 답변 비서 Project(v2)를 열어 둔다. 파일 목록에 규정과 FAQ만 있는 상태로 둔다.
- 강사 Project의 연습 대화를 미리 정리해 두지 말고, 시연에서 정리하는 모습을 보여 준다.
- 키트의 평가 질문 파일과 기대 답변 파일을 메모장으로 나란히 열어 둔다.
- Project 밖에서 비개인화 임시 채팅을 여는 화면을 한 번 확인해 둔다. 시연 2단계에서 쓴다.

## 시연 순서
1. "답은 Project에서, 채점은 Project 밖에서"를 한 줄로 말하고 시작한다. 페이지의 세 단계 표(답변·채점·기록)를 띄운다.
2. Project 파일 목록을 열어 규정과 FAQ만 있는 것을 보여 주고, 연습 대화를 지우는 위치를 보여 준다. 지침란과 파일은 지우지 않는다고 짚는다.
3. Project 새 대화에 평가 질문 파일의 1회차 상자만 붙여 넣는다. 기대 답변을 넣지 않는다는 것을 소리 내어 말한다.
4. Project 밖에서 비개인화 임시 채팅을 열고, 채점 카드에 기대 답변 1회차 부분과 받은 답을 넣어 채점한다.
5. 채점 표를 평가 표에 옮기는 것까지 보여 준다. 채점 결과를 Project 대화에 붙이지 않는다는 것을 강조한다(막힘 지점 sp-d1-06-c).

## 실습 진행
- 1회차와 2회차는 각각 Project의 새 대화에서 받게 한다. 2회차 상자 끝에 21~23번 질문만 붙인다. 기대 답변은 평가 표 아래에 그대로 둔다.
- 질문 한 회차를 받는 데 2분, 한 회차를 채점하는 데 2분 이상 걸린다. 붙여 넣는 글이 길어 초보자는 더 걸린다.
- 답이 끊기면 공통 카드 "출력이 끊기거나 너무 길 때"를 끊긴 대화에 붙이게 한다. 두 번 이상 끊기면 다섯 문항씩 나눠 새 대화에서 묻게 한다(막힘 지점 sp-d1-06-a).
- 채점은 회차마다 새 임시 채팅에서 한다. 임시 채팅은 기록에 남지 않으므로 채점 표를 닫기 전에 평가 표로 옮기게 한다.
- 표본 확인은 AI가 1점을 준 문항 2개와 0점을 준 문항 1개로 한다. AI의 답변 요약이 아니라 받은 답 원문으로 채점하게 한다(막힘 지점 sp-d1-06-b).
- 합계는 점수 칸을 직접 더해 적게 한다. AI가 적은 합계를 그대로 옮기지 않는다. D1-7의 "점수 전"이 이 합계다.
- 먼저 끝난 수강생은 접이식 "잘못된 결과 예시"(관대한 자기채점)를 읽고 자기 채점 표를 다시 보게 한다.

## 흔한 오류
| 증상 | 대응 |
|---|---|
| 질문과 기대 답변을 함께 Project 대화에 넣었다 | 그 대화를 지우고 새 대화에서 질문만 다시 넣게 한다. 기대 답변은 채점할 때만 쓴다 |
| 답을 받은 Project 대화에서 "채점해 줘"라고 했다 | 그 대화를 지우게 한다. 채점은 Project 밖 비개인화 임시 채팅에서 다시 하게 한다 |
| 채점 결과나 틀린 이유를 Project 대화에 붙였다 | 그 대화를 지우게 한다. D1-7에서 다시 평가하기 전에 평가 전 준비를 한 번 더 하게 한다 |
| 평가 파일이 Project 파일 목록에 있다 | 지우게 한다. 규정과 FAQ만 남긴다 |
| 연습 대화를 지우다가 지침이나 파일까지 지우려 한다 | 지우는 것은 대화뿐이라고 다시 말한다. 지침이 바뀌었으면 지침 버전 탭의 전문으로 되돌리게 한다 |
| "대화를 지웠으니 이제 영향이 없나요?"라고 묻는다 | 아직 확인 중인 내용이라고 답한다. 영향이 있다고 보고 줄이는 방법을 쓰는 것이라고 설명한다 |
| 임시 채팅을 찾지 못한다 | 페이지 "잘 안 될 때"의 대안으로 채점하게 한다. Project 밖에서 한다는 것은 지킨다 |
| 채점 표가 한 칸에 모두 들어가 붙는다 | 공통 카드 "표가 깨질 때"를 쓰거나, 번호별로 한 줄씩 옮기게 한다 |
| 거의 모든 문항이 1점이다 | 관대한 채점일 수 있다. 1점 문항부터 받은 답 원문으로 다시 확인하게 한다 |
| 자료에 없음 문항에서 연락처 안내가 없다고 0점을 줬다 | 기대 답변의 "참고(감점 사유 아님)"를 보여 준다. "확인 필요"면 1점이다 |

## 시간이 부족할 때 생략
course.yaml `skip_if_short`와 같다.
- 2회차 실행을 직접 쓴 3문항(21~23번)만으로 줄인다. 11~20번은 강사 화면의 결과를 함께 보고, 평가 표 메모에 "2회차 제공 문항 생략"이라고 적게 한다. 합계는 실행한 문항 수를 만점으로 적는다.
- "더 해보기"(같은 채점 한 번 더)는 건너뛴다. 평가 전 준비, 1회차 답변·채점, 표본 3문항 확인은 줄이지 않는다. 두 학습목표를 확인하는 활동이다.

## 다음 교시로 넘길 것
- 평가 표에 점수, 틀린 이유, 표본 확인 결과, 합계가 있는지 확인한다. D1-7에서 0점 문항의 원인을 찾을 때 쓴다.
- Project 대화에 기대 답변이나 채점 결과가 남아 있지 않은지 확인한다. D1-7의 재평가가 오염되지 않게 한다.
- D1-7의 재평가도 오늘과 같은 방법(평가 전 준비 → 답변 → 채점 → 표본 확인)으로 한다고 예고한다.
