# 강사 안내 — Day 1 · 5교시 평가세트 설계

공개 가능한 진행 안내만 적는다(CD-02). 활동별 시간은 course.yaml `d1-evalset`의 activities를 따른다.
의도된 결함과 연결된 문항은 키트의 강사용 설명(`instructor-notes.md`)을 본다. 수업 중 수강생에게 알리지 않는다.

## 준비
- 키트의 평가 질문 파일과 기대 답변 파일을 메모장으로 나란히 열어 둔다. 시연과 손채점에서 쓴다.
- 강사 화면에 민원 답변 비서 Project(v2)의 파일 목록을 열어 둔다. 규정과 FAQ만 있는 모습을 보여 준다.
- 페이지의 "평가" 표 양식을 띄워 둔다. 수강생이 내 문항을 적는 곳이다.

## 시연 순서
1. "비서를 고치기 전에, 무엇을 맞혀야 하는지 먼저 정한다"고 한 줄로 말하고 시작한다. 개념은 평가 문항·기대 답변·채점 기준 세 가지만 짚는다.
2. 채점 기준 네 가지를 화면에 띄우고 읽는다. "정확과 출처를 모두 충족해야 1점"을 가장 강조한다.
3. 기대 답변 파일의 "참고(감점 사유 아님)"와 "채점 참고" 줄을 하나 보여 준다. 있으면 좋은 내용일 뿐, 점수는 네 가지 기준으로만 정한다고 말한다.
4. 페이지의 7번 가상 답변을 채점한다. 조문이 있어도 금액을 짐작했으므로 0점이라는 것을 보여 준다.
5. 질문 파일과 기대 답변 파일의 쓰는 때를 말한다. 답변을 받을 때는 질문만, 기대 답변은 채점할 때만 쓴다(막힘 지점 sp-d1-05-c). 실행 방법은 D1-6에서 한다고 예고만 한다.
6. Project 파일 목록을 열어 규정과 FAQ만 있는 것을 보여 준다. 평가 파일이 올라가 있으면 점수가 부푼다고 설명한다.

## 실습 진행
- 손채점은 칸마다 O·X만 적게 한다. 채점 이유를 길게 쓰지 않고, 0점인 답에만 한 줄 이유를 쓰게 한다.
- 답변 가에서 "내용이 맞으니 1점"이라고 하는 수강생이 많다. 출처 기준을 다시 짚고 "손채점 답 보기"를 열게 한다.
- 내 문항은 빈 화면에서 쓰지 않게 한다. 페이지의 문항 틀을 복사해 규정 파일을 펴 놓고 채우게 한다(막힘 지점 sp-d1-05-a).
- 문항을 떠올리지 못하면 규정의 조문 하나를 고르고, 그 조문에 대한 민원인 질문을 쓰게 한다.
- 근거 조문은 반드시 규정 파일에서 찾아 적게 한다. 기억으로 쓴 조문 번호는 체크하지 않게 한다.
- 먼저 끝난 수강생은 "잘못된 결과 예시"를 열어 자기 문항과 비교하게 한 뒤 카드로 비판받게 한다(막힘 지점 sp-d1-05-b).
- 카드는 Project 밖 새 채팅에서 쓰게 한다. 기대 답변이 Project 대화에 남지 않게 하기 위해서다.
- 한 번 묻고 읽는 데 2분 정도 걸린다. 지적은 중요한 것 한두 개만 반영하게 한다.

## 흔한 오류
| 증상 | 대응 |
|---|---|
| 평가 질문·기대 답변 파일을 Project 파일로 올렸다 | Project 파일 목록에서 지우게 한다. 규정과 FAQ만 남긴다 |
| 질문과 기대 답변을 함께 비서에게 넣으려 한다 | 답변을 받을 때는 질문만 넣는다고 다시 말한다. 기대 답변은 채점할 때만 쓴다 |
| "모두 알려 주세요"처럼 정답이 여러 개인 질문을 쓴다 | 한 가지만 묻게 고친다. 잘못된 결과 예시의 21번을 함께 본다 |
| 핵심 포인트에 "친절하게"처럼 판단할 수 없는 말을 쓴다 | 받은 답에서 예/아니오로 확인할 수 있는 문장으로 바꾸게 한다 |
| 근거 조문 칸이 비어 있거나 "규정 전체"라고 쓴다 | 규정 파일에서 조문 번호를 찾아 적게 한다. 찾을 수 없으면 "자료에 없음" 유형으로 바꾸게 한다 |
| 자료에 없는 내용을 핵심 포인트로 쓴다 | 규정과 FAQ에서 그 문장을 찾게 한다. 없으면 핵심 포인트에서 뺀다 |
| AI에게 문항을 만들어 달라고 한다 | 카드는 내가 쓴 문항을 비판받는 용도라고 말한다. 대괄호에 내 문항을 넣게 한다 |
| 자료에 없음 문항에 연락처 안내가 없으면 감점한다 | 기대 답변의 "참고(감점 사유 아님)"를 보여 준다. "확인 필요"면 1점이다 |
| 문항에 실제 이름이나 전화번호를 쓴다 | 가상 이름과 010-0000-XXXX 형식의 가상 번호로 바꾸게 한다 |

## 시간이 부족할 때 생략
course.yaml `skip_if_short`와 같다.
- 직접 쓰는 문항을 세 개에서 한 개로 줄인다. D1-6에서는 제공 문항에 그 한 개만 더해 실행한다.
- "더 해보기"(짝의 문항 채점)는 건너뛴다. 손채점 두 개와 Project 파일 목록 확인은 줄이지 않는다. 학습목표를 확인하는 활동이다.

## 다음 교시로 넘길 것
- 평가 표 21~23번 줄에 내 질문이 있고, 표 아래에 기대 답변이 적혀 있는지 확인한다. D1-6에서 제공 문항과 함께 실행한다.
- Project 파일 목록에 규정과 FAQ만 있는지 다시 확인한다. D1-6의 점수가 부풀지 않게 한다.
- D1-6 전에 Project 안의 대화를 늘리지 않게 한다. 오늘은 Project에서 새 대화를 열 일이 없다.
