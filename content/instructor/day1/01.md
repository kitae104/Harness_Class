# 강사 안내 — Day 1 · 1교시 하네스 엔지니어링 이해

공개 가능한 진행 안내만 적는다(CD-02). 활동별 시간은 course.yaml `d1-harness-intro`의 activities를 따른다.

## 시연 순서
1. 입과 안내: 과정의 목표(질문 잘하기가 아니라 환경 설계), 2일 흐름, 실습 자료 규칙(가상 자료·공개 법령만)을 말한다.
2. 로그인 화면과 입력창 위치를 강사 화면으로 보여 준다(막힘 지점 sp-d1-01-a).
3. 체험 질문을 강사 화면에서 두 번 묻고, 두 답을 나란히 띄운 뒤 수강생에게 같은 활동을 시킨다.
4. 비교 체크리스트(내용·형식·근거) 세 항목을 하나씩 짚으며 짝끼리 차이를 말하게 한다(막힘 지점 sp-d1-01-b).
5. Prompt·Context·Harness 비교표와 그림 A(6요소)를 띄우고, "프롬프트를 길게 쓴다고 하네스가 되지 않는다"를 강조한다.
6. 비개인화 임시 채팅을 여는 과정을 시연한 뒤, 기준 질문을 묻고 하네스 대장에 기록하게 한다.

## 흔한 오류
| 증상 | 대응 |
|---|---|
| 로그인이 안 된다(기관 계정 차단, 비밀번호 분실) | 보조강사가 개인 계정 로그인을 돕는다. 해결 전에는 강사 화면을 보며 따라가게 한다 |
| 임시 채팅을 찾지 못한다 | 강사 화면으로 위치를 다시 보여 준다. 화면이 달라졌으면 등록부의 fallback(메모리와 맞춤 지침을 끈 새 대화)으로 진행하고, 대장에 "일반 대화"라고 적게 한다 |
| 체험 질문 두 답이 거의 같다 | 짝의 답과 비교하게 한다. 형식·근거 표시 차이도 "다른 답"임을 짚는다 |
| 답을 고쳐서 기록하려 한다 | 적용 전 기록이므로 틀려 보여도 그대로 적게 한다 |
| 체험 질문의 정답(기한·과태료)을 묻는다 | 이 교시에서 판정하지 않고 D1-4에서 근거 자료로 확인한다고 안내한다 |
