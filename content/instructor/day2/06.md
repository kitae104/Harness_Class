# 강사 안내 — Day 2 · 6교시 내 업무 하네스 제작

공개 가능한 진행 안내만 적는다(CD-02). 활동별 시간은 course.yaml `d2-project-build`의 activities를 따른다. 프로젝트형 교시라 강사 시연은 최소로 하고 순회 지도를 중심으로 한다. 평가 절차는 D1-06과 같다(PRACTICE_DESIGN 3절, CD-17). 예시별 틀리기 쉬운 문항은 각 키트의 강사용 설명 3~4절을 본다.

## 준비
- 강사 화면에 D1-06 페이지를 열어 둔다. 평가 절차를 다시 설명하지 않고 이 페이지의 표(답변·채점·기록)를 짚는다.
- 예시별 "Project 파일로 올리는 파일"과 "채팅에 첨부하는 파일"을 칠판에 적어 둔다(페이지의 근거 자료 표와 같다).
- 업무용 폼(선택)을 쓸 수 있게, 현장 점검·수요조사 폼 사본 링크를 준비했다면 나눌 수 있게 둔다. 없으면 폼 문항 틀로 새로 만들게 한다.

## 도입 (시연 대신 짧게)
1. 설계서의 칸마다 담는 곳이 다르다는 표("설계 예시")를 짚는다. "AI는 설계서를 읽지 않는다. 지침란과 Project 파일만 본다"고 말한다.
2. 지침은 이번에 직접 쓴다고 알린다. 카드는 막혔을 때 설계서와 대조하는 용도다.
3. 평가는 D1-6과 같다. 답변은 Project 새 대화에 질문만, 채점은 Project 밖 비개인화 임시 채팅이라고 한 번만 말한다.

## 순회 지도
- **지침과 Project(13분)**: 지침서 틀의 다섯 제목을 그대로 두고 쓰는지 본다. 사실(기한·금액·서류 목록)을 지침에 쓰는 수강생이 많다. "그 사실은 어느 파일에 있나요?"를 묻는다(막힘 지점 sp-d2-06-a).
- 지침을 채팅창에 붙이는 수강생이 아직 있다. 지침란 저장과 지침 버전 v1 기록을 확인한다.
- **근거 업로드(5분)**: 파일 목록을 직접 본다. 키트 폴더를 통째로 올리는 경우가 가장 흔하다. 평가 파일·지침서 틀·입력 자료가 있으면 바로 지우게 한다(막힘 지점 sp-d2-06-c).
- **입력 자료가 있는 예시**(현장 점검, 수요조사, 회의록): 평가 답변을 받을 때 입력 파일을 그 대화에 첨부했는지 본다. 첨부 없이 물으면 "자료가 없다"는 답이 나와 점수가 낮아진다.
- **채점**: 카드의 [업무 이름]을 바꿨는지 본다. 수요조사·회의록 예시는 출처 규칙 한 줄을 더했는지 본다. 더하지 않으면 양식 항목을 밝힌 답도 출처 X가 될 수 있다.
- **표본 확인**: 5문항 중 3문항이다. 1점 2개, 0점 1개(없으면 1점 3개)를 직접 채점하게 한다.
- **결과가 이상할 때**: 공통 카드를 그 대화에 쓰게 하되, 채점·기록을 마친 뒤에 쓰게 한다. 기대 답변을 넣지 않게 한다(막힘 지점 sp-d2-06-b).
- 만점이 나온 수강생은 Project 파일 목록부터 본다. 평가 파일이 올라가 있지 않은데 만점이면 D2-7에서 6~10번을 더 실행하게 한다.

## 흔한 오류
| 증상 | 대응 |
|---|---|
| 지침에 규정 조문 내용을 옮겨 적었다 | 조문은 근거 파일에 있고, 지침은 "근거 조문을 밝힌다" 같은 행동 규칙만 둔다고 말한다 |
| 지침을 채팅창에 붙였다 | 지침란으로 옮기게 한다. 채팅에 붙인 지침은 그 대화에만 적용된다 |
| 키트 파일을 모두 Project에 올렸다 | 근거 파일만 남기고 지운다. 기대 답변이 들어가면 점수가 부푼다(CD-17) |
| 입력 자료(CSV·회의 메모)를 Project 파일로 올렸다 | Project 파일에서 지우고 평가하는 대화에 첨부하게 한다(CD-07) |
| 5문항과 기대 답변을 함께 붙여 답을 받았다 | 그 대화를 지우고 새 대화에서 질문만 다시 넣게 한다 |
| Project 안에서 채점했다 | 그 대화를 지운다. 채점은 Project 밖 비개인화 임시 채팅에서 다시 한다 |
| 채점 카드가 조문이 없다며 양식 예시 답을 모두 출처 X로 줬다 | 페이지의 출처 규칙 한 줄을 채점 규칙에 더해 다시 채점하게 한다 |
| 임시 채팅을 찾지 못한다 | 강사 화면을 보여 준다. 그래도 없으면 페이지의 대안으로 채점하되 Project 밖에서 한다 |
| 업무용 폼을 꼭 만들어야 하냐고 묻는다 | 선택이다(CD-09). 설계서 ③ 도구 칸은 폼이 없어도 반드시 쓴다 |

## 시간이 부족할 때 생략
course.yaml `skip_if_short`와 같다.
- 업무용 폼(선택)은 건너뛴다. 설계서 ③ 도구 칸은 그대로 둔다.
- 카드는 막힌 수강생만 쓴다. 지침 저장, 근거 업로드, 평가 5문항 실행·채점·표본 확인은 줄이지 않는다. 두 학습목표를 확인하는 활동이다.
- 그래도 부족하면 표본 확인을 0점 1문항과 1점 1문항으로 줄이고, 줄였다는 것을 평가 표에 적게 한다.

## 다음 교시로 넘길 것
- 평가 표 1~5번에 점수와 틀린 이유가 있고, 합계가 설계서 ④ 칸의 현재 점수에 적혀 있는지 확인한다. D2-7의 "점수 전"이다.
- 원인을 찾느라 연 대화와 결과 이상 카드 대화는 D2-7 재평가 전에 지운다고 예고한다.
- 0점이 없는 수강생을 기억해 둔다. D2-7에서 6~10번을 더 실행하게 한다.
