# 강사 안내 — Day 2 · 1교시 구글 폼으로 입력 구조화

공개 가능한 진행 안내만 적는다(CD-02). 활동별 시간은 course.yaml `d2-forms`의 activities를 따른다.

## 준비
- 강사 화면에 빈 구글 폼 편집 화면과 Day 1의 민원 답변 비서 Project v3를 함께 열어 둔다. "지난 시간에서 이어가기"에서 Project를 한 번 보여 주고 폼으로 넘어간다.
- 강사 공용 폼의 응답 주소를 칠판이나 메신저로 바로 나눌 수 있게 준비한다. 공용 폼이 준비 전이면 페이지에 대안(제공 CSV)이 보인다.
- 수강생마다 역할카드 시작 번호(1~15)를 미리 나눠 둔다. 15번 다음은 1번이다.
- 시연용으로 내 폼에 응답 시트가 연결된 상태와 연결 전 상태를 둘 다 보여 줄 수 있게 한다.

## 시연 순서
1. Day 1 끝에 남긴 "③ 도구"를 짚고, 오늘은 입구를 만든다고 말한다. 핵심 개념(입력 구조화, 입구에서 줄이기, 쌓이는 곳)은 한 줄씩만 말한다.
2. 폼을 처음부터 만들기로 열고 문항 두 개(접수일, 민원 유형)를 만든다. 문항 이름이 시트의 열 이름이 된다고 강조한다.
3. 미리보기로 응답 한 건을 보내고, 응답 시트에 한 줄이 쌓이는 모습을 보여 준다.
4. 설정에서 이메일 수집을 끄는 곳과 응답 탭에서 시트를 연결하는 곳을 천천히 짚는다(막힘 지점 sp-d2-01-a).
5. 페이지의 "잘못된 결과 예시"(성명·생년월일·주소를 받는 폼)를 띄우고, "이 문항이 없으면 분류를 못 하는가?"를 묻는다(막힘 지점 sp-d2-01-b).

## 실습 진행
- 폼 만들기는 폼 문항 파일(`form-questions.md`)을 옆에 두고 글자 그대로 옮기게 한다. 문항 이름과 민원 유형 선택지가 CSV·분류 기준표와 같아야 D2-2가 매끄럽다.
- 문항 5개가 벅차면 1·2·3번 세 개만 만들게 한다(skip_if_short). 이메일 수집 끄기는 줄이지 않는다.
- "AI 도움받기"의 질문은 Project 밖 새 채팅에서 쓴다. 문항 목록만 넣고 응답 내용은 넣지 않게 한다. 시간이 부족하면 건너뛴다.
- 공용 폼 응답은 카드 3장, 3번이다. 민원 유형은 수강생이 고르게 둔다. 일부러 틀린 유형을 고른 응답도 D2-2의 확인 필요(B) 연습 재료가 된다.
- 역할카드 7번·12번은 내용 칸에 가상 이름·주소를 그대로 적게 되어 있다. 고치지 말고 그대로 적게 한다. D2-2 첨부 전 점검의 대상이다.
- 공유 범위는 실습에서 "나만"으로 두게 한다. 실제 업무에서는 부서 담당자만 추가한다고 말한다.

## 흔한 오류
| 증상 | 대응 |
|---|---|
| 이메일 수집 설정을 찾지 못한다 | 강사 화면으로 설정 위치를 다시 보여 준다. 미리보기에서 이메일 칸이 사라졌는지로 확인하게 한다 |
| 문항 이름을 줄이거나 바꿔 적었다("민원 종류", "전입신고") | 폼 문항 파일과 글자 그대로 맞추게 한다. D2-2에서 열과 유형이 어긋나는 이유를 한 줄로 설명한다 |
| 이름·연락처를 필수로 넣었다 | "이 문항이 없으면 분류를 못 하는가?"를 묻는다. 이름 문항은 빼고, 연락처는 필수를 끄게 한다 |
| 선택지를 한 칸에 모두 적었다 | 선택지는 한 칸에 하나씩 넣게 한다 |
| 응답 시트 연결을 찾지 못한다 | 응답 탭 위치를 다시 보여 준다. 응답을 한 건 받은 뒤 연결해도 된다고 말한다 |
| 공용 폼 대신 옆 사람 폼에 응답했다 | 공용 폼에 다시 응답하게 한다. 서로의 폼에는 응답하지 않는다(CD-19) |
| 역할카드의 가상 주소를 "개인정보라서" 빼고 적었다 | 이번에는 카드대로 적게 한다. 실제 민원에도 섞여 들어오며, D2-2에서 사람이 찾아내는 연습을 한다고 설명한다 |
| 자기 실제 이름이나 번호를 적었다 | 그 응답을 강사가 지운다고 알리고, 가상 번호(010-0000-XXXX)로 다시 응답하게 한다 |
| 구글 계정에 로그인할 수 없다(교육망, 기관 계정) | 짝의 화면으로 함께 확인하게 한다. 공용 폼 응답은 짝의 브라우저에서 해도 된다 |

## 시간이 부족할 때 생략
course.yaml `skip_if_short`와 같다.
- 폼 문항을 1·2·3번 세 개로 줄인다. 문항 이름은 그대로 둔다.
- "AI 도움받기"의 문항 점검 질문과 "더 해보기"는 건너뛴다. 이메일 수집 끄기, 공용 폼 응답, 공유 범위 확인은 줄이지 않는다. 두 학습목표를 확인하는 활동이다.

## 다음 교시로 넘길 것
- 공용 폼 응답 건수를 확인한다. 모자라면 D2-2는 제공 CSV(가상 민원 30건)로 진행한다고 미리 알린다.
- 수강생이 키트 zip을 내려받았는지 확인한다. D2-2에서 `classification-table.md`와 `civil-requests-30.csv`를 쓴다.
- D2-2 시작은 첨부 전 개인정보 점검이라고 예고한다. 오늘 일부러 적은 가상 이름·주소가 그 대상이다.

## 강의 준비
- 강사 공용 폼을 `form-questions.md` 문항 그대로 만들고(이메일 수집 끔, 응답 시트는 강사만), 응답 주소를 `content/external-links.yaml`의 `form-shared-civil-intake`에 적는다(prep/google-sheets-forms.md 2절). 폼·시트를 소유할 계정은 아직 정하지 않았다 [TBD: OQ-06].
- 리허설 응답을 지우고 수업을 시작한다. 이전 기수 응답이 섞이지 않게 한다.
- 수강생 수에 맞춰 역할카드 시작 번호 배정표를 만든다.
- 강의실 PC에서 구글 로그인, 폼 만들기, 공용 폼 응답이 되는지 확인한다(교육망 차단 대비). 막히면 짝과 함께 하는 방식으로 진행한다.
- 이메일 수집 끄기와 응답 시트 연결의 실제 화면 위치를 수업 직전에 다시 확인한다. 구글 폼 화면은 예고 없이 바뀔 수 있다.
