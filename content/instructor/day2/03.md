# 강사 안내 — Day 2 · 3교시 초안 생성과 사람 검토

공개 가능한 진행 안내만 적는다(CD-02). 활동별 시간은 course.yaml `d2-drafts`의 activities를 따른다.

## 준비
- 강사 화면에 민원 답변 비서 Project를 열어 둔다. 지침란에 D2-2 끝에서 옮긴 분류 규칙이 있어야 한다.
- 시연용으로 1번 민원(이사한 지 5일, 기한 문의)의 초안을 미리 받아 둔다. 검토 기준 4가지를 모두 통과하는 초안이면 된다.
- 키트 `day2-civil-intake`의 `review-criteria.md`를 강사 화면 옆 창에 열어 둔다. Project에 올리지 않는다.
- 규정 파일(`day1-civil` 키트 `rule-move-in.md`)을 열어 둔다. 근거 조문을 직접 찾아 보일 때 쓴다.

## 시연 순서
1. 지침란 맨 아래의 "여러 건 분류 규칙"을 강사 화면으로 보여 주고, "-점검" 표 파일을 첨부해 한 줄 요청만 보낸다. 카드 없이도 같은 열의 표가 나오는 것을 보여 주고, 다섯 건을 골라 분류 대장과 비교하게 한다. 반복되는 규칙은 지침이 맡는다는 것을 한 문장으로 말한다(PRACTICE_DESIGN 6절 3번). 30건 표가 나오는 데 시간이 걸리므로 수강생과 동시에 보낸다.
2. 초안과 결재 비유는 한 줄로 말한다. "AI는 기안, 사람은 결재. 결재 전 문서는 나가지 않는다."
3. 미리 받아 둔 1번 초안을 띄우고 검토 기준 4가지(초안 표시 → 개인정보 → 금지 위반 → 근거)를 순서대로 짚는다. 근거 조문(제3조)은 규정 파일에서 직접 찾아 보인다(막힘 지점 sp-d2-03-a).
4. 판정은 승인이다. "승인해도 사람이 한 번 더 읽고 보낸다. 보내는 것은 AI가 아니다"를 꼭 말한다.
5. 카드를 Project 안 새 대화에 붙이고 대괄호 자리에 5건을 넣는 것까지 보여 준다. 요청에 분류 규칙을 다시 붙이지 않는다고 짚는다(막힘 지점 sp-d2-03-c).

## 실습 진행
- 초안 받기에 AI 왕복 1~2회(답이 끊기면 "계속")가 든다. 5건을 한 번에 넣게 한다. 30건 전부를 넣지 않는다.
- 검토는 한 건에 2분 정도다. 검토 기준 4가지를 차례로 보게 하고, 체크는 조문을 찾은 뒤에만 하게 한다.
- 5번은 확인 필요(A) 건이다. 초안이 좋아도 원칙은 보류라는 것을 순회하며 확인한다(키트 강사용 설명 5절).
- 24번은 D2-2에서 개인정보를 지운 상태로 넣는다. 지우지 못한 수강생의 초안에 이름·주소가 나오면 좋은 사례다. 수정으로 판정하게 하고 D2-4 점검에서 다시 본다.
- 먼저 끝난 수강생은 접이식 "잘못된 결과 예시"를 열어 공손한 말투 때문에 승인한 판정의 문제를 읽게 한다(막힘 지점 sp-d2-03-b).
- 초안 검토 기록은 한 건에 한 줄, 판정 칸만 채운다. 자유 서술은 검토 메모 한 줄로 줄인다.

## 흔한 오류
| 증상 | 대응 |
|---|---|
| 카드에 D2-2 분류 규칙을 다시 붙였다 | 지침란에 규칙이 있는지 보게 하고, 요청에서는 지우게 한다. 규칙이 지침에 없으면 D2-2 끝의 "카드를 지침으로 옮기기"를 먼저 한다 |
| AI가 검토 칸을 "승인"으로 채웠다 | 그 칸은 무시하고 사람이 판정하게 한다. AI가 채운 판정은 검토가 아니라고 설명한다 |
| 말투가 공손하고 조문이 있어 모두 승인했다 | 검토 기준 4가지를 다시 차례로 보게 한다. 특히 금액과 개인정보를 먼저 찾게 한다 |
| 초안에 "보통 ○만 원" 같은 금액이 나왔다 | 금지 위반이다. 금액 문장만 지우면 되면 수정, 금액 안내가 답의 중심이면 보류로 판정하게 한다(review-criteria.md) |
| 5번을 승인했다 | 분류 대장에서 확인 필요였던 건은 원칙이 보류라고 짚는다 |
| 16번 대리 신고 서류를 초안이 적었다 | D1-7에서 FAQ를 보충했는지 묻는다. 보충하지 않았다면 서류는 자료에 없으므로 수정(확인 필요로 바꿈)이다 |
| 답이 중간에 끊긴다 | "계속"이라고 보내게 한다. 계속 끊기면 5건을 두 번에 나눠 보내게 한다 |
| 초안을 AI에게 고쳐 달라고 한다 | 수정은 사람이 직접 한다. 고친 내용을 검토 메모에 적게 한다 |

## 시간이 부족할 때 생략
course.yaml `skip_if_short`와 같다.
- 공문 PDF 요약은 이 페이지에 활동으로 두지 않았다. 시간이 남는 반에서만 말로 소개한다.
- 그래도 부족하면 보고 요약 확인을 건너뛰고 초안 5건의 판정과 기록만 한다. 두 학습목표를 확인하는 활동이다.

## 다음 교시로 넘길 것
- 초안 검토 기록에 5줄이 있고, 판정과 검토자가 적혀 있는지 확인한다. D2-4 안전장치 점검에서 이 기록을 다시 본다.
- 판정에서 "문제"가 나온 곳(초안 표시 누락, 개인정보, 금액)을 메모하게 한다. D2-4에서 지침에 규칙을 더할 때 쓴다.

## 강의 준비
- 카드 `card-draft-replies`를 교육용 Plus 계정의 테스트 Project에서 실제로 실행하고 `tested_at`·`tested_by`를 채운다(prep/card-tests.md Day 2 카드). 5번 금액 단정과 24번 개인정보 옮김이 나타나는지 본다.
- 시연용 1번 초안을 수업 전에 받아 둔다. 수업 중 AI 답이 달라도 검토 기준으로 판정하는 시연은 같다.
- 공문 PDF 요약을 더 해보기로 넣을지 정한다. 넣으려면 교육용 가상 공문 PDF를 키트에 더해야 한다.
