## 이번 시간에 할 일

D1-5에서 만든 평가세트로 민원 비서를 실제로 평가해 점수를 얻습니다.
답은 Project에서 받고, 채점은 Project 밖에서 따로 합니다. 이렇게 나눠야 점수를 믿을 수 있습니다.
마지막으로 AI가 매긴 점수를 사람이 세 문항만 직접 확인하고, 하네스 대장 평가 표에 기록합니다.

## 필수 경로

1. 강사 시연에서 답을 받는 곳과 채점하는 곳이 다르다는 것을 봅니다.
2. 평가 전 준비: Project 파일 목록을 확인하고, Project 안의 연습 대화를 정리합니다.
3. Project 새 대화에 질문만 넣어 두 번(1~10번, 11~23번) 답을 받습니다.
4. Project 밖 비개인화 임시 채팅에서 채점 카드로 두 회차를 채점하고, 평가 표에 옮깁니다.
5. 세 문항을 직접 채점해 AI 채점과 비교하고, 합계 점수를 적습니다.

## 지난 시간에서 이어가기

D1-5에서 평가 문항과 기대 답변, 채점 기준을 정했습니다. 내 문항 세 개도 평가 표에 더했습니다.
기준은 생겼지만, 아직 비서를 재 보지는 않았습니다.
오늘은 그 기준으로 비서의 점수를 처음 잽니다. 이 점수가 D1-7에서 고칠 곳을 알려 줍니다.

<details>
<summary>핵심 개념 — 답변과 채점을 나누는 이유</summary>

평가는 **답변**과 **채점** 두 단계입니다. 두 단계를 한 곳에서 하면 점수가 부풉니다.

- **답변**: 비서가 평소처럼 답하게 합니다. 그래서 Project 안에서, **질문만** 넣습니다.
- **채점**: 받은 답을 기대 답변과 대조합니다. 그래서 **Project 밖**에서, 기대 답변과 함께 넣습니다.
- **표본 확인**: AI 채점은 관대할 수 있습니다. 사람이 몇 문항을 직접 채점해 비교합니다.

답변 단계에 기대 답변이 들어가면, 비서는 정답을 보고 답합니다. 실력이 아니라 정답을 옮긴 점수가 됩니다.
Project 안에서 채점하면 정답과 틀린 이유가 Project 대화에 남습니다.
같은 Project의 다른 대화가 다음 답에 영향을 줄 수 있습니다. <Feature id="chatgpt-project-memory" show="detail" />

시험 문제를 낸 사람이 답안지를 미리 보여 주지 않고, 채점은 답안을 걷은 뒤 따로 하는 것과 같습니다.

</details>

## 실습 — 답변 받기(두 번 실행)

평가 질문 23문항을 두 번에 나눠 묻습니다. 한 번에 넣으면 답이 길어져 중간에 끊기기 쉽습니다.

**1회차(1~10번)**

1. 민원 답변 비서 Project에서 **새 대화**를 엽니다.
2. 평가 질문 파일의 "1회차(1~10번)" 상자를 그대로 복사해 붙여 넣고 보냅니다.
3. 받은 답을 끝까지 확인합니다. 10번까지 모두 답했는지 번호를 셉니다.
4. 받은 답 전체를 복사해 메모장에 붙여 둡니다. 채점할 때 씁니다.

**2회차(11~23번)**

1. 같은 Project에서 **새 대화**를 하나 더 엽니다.
2. 평가 질문 파일의 "2회차" 상자를 복사하고, 그 끝에 평가 표의 21~23번 **질문만** 이어 붙입니다.
3. 붙여 넣고 보낸 뒤, 23번까지 모두 답했는지 번호를 셉니다.
4. 받은 답 전체를 메모장에 붙여 둡니다.

21~23번의 기대 답변은 평가 표 아래에 두고, 여기에는 넣지 않습니다.

## 실습 — 채점과 기록

한 회차에 임시 채팅 하나씩, 두 번 채점합니다.

**채점합니다.**

1. Project 밖에서 비개인화 임시 채팅을 엽니다.
2. 채점 카드를 복사해 붙여 넣습니다. 아직 보내지 않습니다.
3. "[질문과 기대 답변]" 자리에 기대 답변 파일의 1회차(1~10번) 부분을 붙여 넣습니다.
4. "[받은 답]" 자리에 1회차에서 받은 답 전체를 붙여 넣고 보냅니다.
5. 2회차는 새 임시 채팅에서 같은 순서로 합니다. 기대 답변은 2회차 부분에 평가 표 아래의 21~23번 기대 답변을 더합니다.

**기록합니다.** 임시 채팅은 기록에 남지 않습니다. 채팅을 닫기 전에 옮깁니다.

<ExternalLink id="sheet-harness-ledger" tab="eval" />

1. 채점 표를 평가 표의 같은 번호 줄에 옮깁니다. 열 이름이 같아 그대로 붙일 수 있습니다.
2. 0점인 문항은 "틀린 이유" 칸이 채워져 있는지 봅니다.
3. 점수 칸을 직접 더해, 표 아래에 합계(23점 만점)를 적습니다. D1-7의 "점수 전"이 이 합계입니다.

<Callout kind="주의" title="채점 결과는 Project 대화에 붙이지 않습니다">

채점 표와 틀린 이유는 하네스 대장 평가 표에만 적습니다.
"이 문항이 왜 틀렸는지" Project에 물어보고 싶어도, 오늘은 묻지 않습니다.
정답 내용이 Project 대화에 남으면 D1-7에서 다시 평가할 때 비서가 그것을 참고할 수 있습니다.
틀린 원인은 D1-7에서 질문과 받은 답만 넣어 찾습니다.

</Callout>

## 실습 — 사람이 3문항 확인하기

AI 채점을 그대로 믿지 않습니다. 세 문항을 직접 채점해 AI 점수와 비교합니다.

**이렇게 고릅니다.** AI가 **1점을 준 문항 2개**와 **0점을 준 문항 1개**를 고릅니다. 0점이 없으면 1점 문항 3개를 고릅니다.
1점 문항을 더 많이 보는 이유는, AI 채점이 관대하게 1점을 주는 실수가 더 흔하기 때문입니다.

**이렇게 채점합니다.** D1-5의 손채점과 같습니다. 받은 답 원문과 기대 답변을 나란히 놓고, 메모장에 아래 틀을 채웁니다.

```
○번: 정확( ) 출처( ) 금지 위반 없음( ) → 내 점수( ) / AI 점수( ) / 같음·다름
```

<CopyButton text={"○번: 정확( ) 출처( ) 금지 위반 없음( ) → 내 점수( ) / AI 점수( ) / 같음·다름"} label="표본 확인 틀 복사" />

점수가 다르면 **내 점수로 고치고**, 합계도 다시 냅니다. 다른 이유를 한 줄 덧붙입니다.

| 9 | 사진이 없는 카드도 신분증으로 쓸 수 있나요? | 신분증은 사진이 붙은 공공기관 발급 증명서라 사진 없는 카드는 해당하지 않는다고 답함. 근거 없음 | O | X | 없음 | 0 | 근거 조문(제6조)을 밝히지 않음 |
| 10 | 전입신고 수수료는 얼마인가요? | 자료에 없어 확인이 필요하다고 답함 | O | 면제 | 없음 | 1 | |

</div>

- 정확·출처가 모두 O이고 금지가 "없음"인 문항만 1점입니다.
- 9번은 내용이 맞아도 조문이 없어 0점입니다. 틀린 이유에 무엇이 빠졌는지 적혀 있습니다: <Source id="fictional-day1-move-in-rule" article="제6조" />.
- 10번은 자료에 없음 문항이라 출처가 "면제"이고, 연락처 안내가 없어도 1점입니다.

**표본 확인의 예**

```
6번: 정확(O) 출처(O) 금지 위반 없음(O) → 내 점수(1) / AI 점수(1) / 같음
7번: 정확(O) 출처(O) 금지 위반 없음(O) → 내 점수(1) / AI 점수(1) / 같음
9번: 정확(O) 출처(X) 금지 위반 없음(O) → 내 점수(0) / AI 점수(0) / 같음
```

- 세 문항 모두 받은 답 원문을 다시 읽고 채점했습니다. AI의 답변 요약만 보고 채점하지 않았습니다.

</details>

<summary>잘못된 결과 예시 — 관대한 자기채점</summary>

> 교육용 가상 자료입니다. 그럴듯하지만 믿을 수 없는 채점의 예입니다.

답을 받은 **Project 대화에 이어서** "방금 네 답을 채점해 줘"라고 하고 기대 답변을 붙여 넣었습니다. 이렇게 돌아왔습니다.

| 번호 | 답변 요약 | 정확 | 출처 | 금지 | 점수 | 틀린 이유 |
|---|---|---|---|---|---|---|
| 7 | 과태료 부과 대상이 될 수 있고, 보통 ○만 원 안팎이라고 안내함. 근거 제7조 | O | O | 없음 | 1 | |
| 9 | 신분증은 사진이 붙은 공공기관 발급 증명서라 사진 없는 카드는 해당하지 않는다고 답함 | O | O | 없음 | 1 | |

전체 23문항 중 22문항이 1점이었고, "대체로 잘 답했습니다"라는 말이 붙어 있었습니다.

**어디가 왜 틀렸나**

- **금지 위반을 놓쳤습니다(7번)**: 금액을 짐작해 말했으니 금지 위반이고 0점입니다. 규정은 금액을 정하지 않습니다: <Source id="fictional-day1-move-in-rule" article="제7조" />.
- **출처를 너그럽게 봤습니다(9번)**: 답에 조문이 없는데 출처를 O로 줬습니다. 내용이 맞으니 괜찮다고 본 것입니다.
- **자기 답을 채점했습니다**: 답한 비서가 같은 대화에서 자기 답을 채점하면, 자기 답을 좋게 보는 쪽으로 기울기 쉽습니다.
- **정답이 Project에 남았습니다**: 기대 답변과 채점 결과가 Project 대화에 들어갔습니다. D1-7의 재평가가 이 정답을 참고할 수 있습니다.

**이렇게 알아봅니다.** 채점 표를 평가 표에 옮기기 전에 세 가지를 확인합니다.

<summary>잘 안 될 때</summary>

- **답이 중간에 끊깁니다.** 위 "출력이 끊기거나 너무 길 때" 카드를 끊긴 그 대화에 붙여 이어 받습니다. 두 번 이상 끊기면 다섯 문항씩 나눠 새 대화에서 다시 묻습니다.
- **채점 표가 중간에 끊깁니다.** 새 임시 채팅에서 다섯 문항씩 나눠 채점합니다. 기대 답변과 받은 답도 같은 번호만 넣습니다.
- **채점 카드에 넣을 글이 너무 깁니다.** 1회차를 1~5번, 6~10번으로 나눠 두 번 채점합니다. 평가 표에는 같은 줄에 이어서 옮깁니다.
- **임시 채팅을 찾지 못합니다.** 강사 화면을 다시 봅니다. 그래도 없으면 아래 대안으로 채점하되, Project 밖에서 합니다.

- **AI가 답을 새로 써 줍니다.** 채점 카드를 처음부터 다시 붙였는지 봅니다. 새로 쓴 답은 쓰지 않고, 받은 답 원문으로 채점합니다.
- **채점 결과를 Project 대화에 붙였습니다.** 그 대화를 지웁니다. D1-7에서 다시 평가하기 전에 평가 전 준비를 한 번 더 합니다.
- **평가 표를 찾지 못합니다.** 위 "평가" 표 양식을 복사해 메모장이나 내 구글 시트에 붙여 적습니다.

<summary>더 해보기 — 같은 채점을 한 번 더</summary>

AI 채점이 얼마나 흔들리는지 봅니다. 기록을 모두 마친 뒤에만 합니다.

1. 새 비개인화 임시 채팅을 열고, 1회차를 같은 채점 카드로 한 번 더 채점합니다.
2. 두 채점 표에서 점수가 다른 문항을 찾습니다.
3. 다른 문항이 있으면 받은 답 원문으로 직접 채점하고, 평가 표의 점수를 내 판단으로 맞춥니다.

## Harness에서 무엇을 바꿨는가

민원 비서의 **검증(Evals)** 이 처음으로 점수가 되었습니다. 이제 "좋아졌다"를 숫자로 말할 수 있습니다.
점수와 틀린 이유는 하네스 대장 평가 표에 **기록(Observability)** 으로 남았습니다. 다음에 고칠 곳을 여기서 찾습니다.
답변과 채점을 나누고, 정답을 Project에 넣지 않은 것은 **안전장치(Guardrails)** 입니다. 점수가 부풀지 않게 지킵니다.
