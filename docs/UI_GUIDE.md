# UI 디자인 가이드

## 디자인 원칙
1. **교육용 도구처럼 보여야 한다.** 마케팅 랜딩 페이지가 아니라 강의 중 계속 보는 교안이다.
2. **지금 할 일이 먼저 보여야 한다.** 학습목표(레이아웃이 자동 표시) 바로 다음, 본문 첫머리에 이번 시간에 할 일과 필수 경로(3~5단계). 설명·예시·강사 안내는 접이식.
3. **강의실 두 화면을 전제한다.** 강사는 프로젝터(큰 글씨, 발표 모드), 수강생은 한쪽에 사이트, 한쪽에 ChatGPT를 띄운다(창 폭 절반에서도 읽혀야 함).
4. **오프라인에서도 동작한다.** 외부 CDN·웹폰트 없음, 인터랙션은 인라인 스크립트 또는 `<details>`(ARCHITECTURE 7절).

## AI 슬롭 안티패턴 — 하지 마라
| 금지 사항 | 이유 |
|---|---|
| backdrop-filter: blur() | glass morphism은 AI 템플릿의 가장 흔한 징후 |
| gradient-text | AI가 만든 SaaS 랜딩의 1번 특징 |
| "Powered by AI" 배지 | 장식일 뿐 수강생에게 가치 없음 |
| box-shadow 글로우 애니메이션 | 네온 글로우 = AI 슬롭 |
| 보라/인디고 브랜드 색상 | "AI = 보라색" 클리셰 |
| 모든 카드에 같은 큰 둥근 모서리 | 템플릿 느낌 |
| 배경 gradient orb, 3D, 과도한 애니메이션 | 수업 집중 방해 |
| 복잡한 메뉴, 히어로 이미지 | 교시 이동이 느려짐 |

## 색상 [PROVISIONAL — Phase 1에서 확정]
밝은 배경 기본(프로젝터 가독성), 다크 모드는 시스템 설정을 따른다. 색은 의미에만 쓴다.
| 용도 | 값(라이트) | 쓰는 곳 |
|---|---|---|
| 배경 | #ffffff | 페이지 |
| 면 | #f5f6f7 | 카드, 코드·프롬프트 블록 |
| 본문 텍스트 | #1f2328 | 본문 |
| 보조 텍스트 | #57606a | 설명, 캡션 |
| 강조(링크·주요 버튼) | #0b5cad | 링크, 복사 버튼 |
| 주의 | #9a6700 배경 #fff8c5 | 주의사항, "확인 필요" |
| 위험 | #cf222e 배경 #ffebe9 | 개인정보·금지 |
| 완료 | #1a7f37 | 체크 완료, 예상 결과 |
명도 대비는 본문 4.5:1 이상.

## 타이포그래피
| 용도 | 스타일 |
|---|---|
| 페이지 제목 | 2rem, 굵게 |
| 섹션 제목 | 1.4rem, 굵게, 위 여백 크게 |
| 본문 | 1.0625rem(17px) 이상, 행간 1.75 |
| 프롬프트·코드 | 고정폭, 1rem, 행간 1.6, 자동 줄바꿈 |
| 발표 모드 | 본문 1.375rem 이상, 사이드바 숨김 |
글꼴은 시스템 한글 글꼴 스택(맑은 고딕, Apple SD Gothic Neo, Noto Sans KR 순). 웹폰트를 불러오지 않는다.

## 레이아웃
- 본문 최대 폭 약 46rem, 좌측 정렬. 가운데 정렬 금지(목록·단계가 많음).
- 상단: 현재 위치 "Day 1 · 3교시 — 제목", 진행 표시. 하단: 이전/다음 교시.
- 사이드바: Day별 교시 목록(현재 교시 강조). 폭이 좁으면 접힘.
- 375px 폭에서 가로 스크롤 없음.

## 컴포넌트
### AI에게 도움받기 카드
```
┌ AI에게 도움받기 · [붙여넣을 곳 배지: 지침란 / Project 채팅 / 새 채팅 / 임시 채팅]
│ 언제: …        무엇을 넣나: …
│ [직접 쓰기] 5칸 뼈대            ← 교시 기본 단계에 따라 처음 보이는 단계가 다름
│ ▸ 힌트 보기(바꿔 쓰기)   ▸ 전체 보기(따라 쓰기)
│ ┌ 프롬프트 (대괄호 부분 강조) ────────────── [복사] ┐
│ │ …                                                  │
│ └───────────────────────────────────────────────────┘
│ ☐ 대괄호를 모두 바꿨나요?
│ ▸ 문장별 해설(①~⑥ 배지 + 이유)
│ ▸ 확인할 것 · 그대로 믿으면 안 되는 부분 · 다음 행동
└
```
- 복사 버튼은 키보드로 누를 수 있고, 성공 시 "복사됨" 텍스트를 표시한다(색만으로 알리지 않음).
- 대괄호 부분은 배경색 + 밑줄로 강조한다.

### 기타
| 컴포넌트 | 규칙 |
|---|---|
| 주의·팁·검토 박스 | 왼쪽 굵은 선 + 옅은 배경. 아이콘은 선택, 아이콘만으로 의미 전달 금지 |
| 체크리스트 | 체크 상태는 브라우저에만 저장, "진행 초기화" 버튼(공용 PC) |
| 필수/선택 배지 | 텍스트 배지. 선택(Codex 등)은 회색 |
| 예상 결과 / 잘못된 결과 | 나란히 또는 위아래, 잘못된 결과 바로 아래에 "어디가 왜 틀렸나" |
| 제품 정보 표시 | 기능명 옆에 작은 글씨로 "확인일 YYYY-MM-DD" |
| 제품 정보 상세·대안(`Feature show`) | `detail`은 본문 문단 안의 일반 텍스트로, `fallback`은 "안 될 때" 제목을 붙인 주의 박스로 표시. 두 형식 모두 확인일을 함께 표시 |
| 외부 자원 대안 표 양식(`ExternalLink tab`) | "준비 중" 텍스트 배지와 `fallback` 문구 → 탭 이름을 제목으로 한 빈 표(열 이름만) → 표 오른쪽 위 [복사] 버튼(열 이름을 탭으로 구분한 한 줄을 복사, 시트에 붙이면 칸이 나뉨) |

## 도식과 캡처
- 제안서 그림 A(6요소 개념도), B(도구 3종 역할), C(폼→시트→ChatGPT→시트 한 바퀴), 그림 4(개선 루프), 그림 7(설계서 양식)은 SVG 도식으로 다시 만든다. 텍스트는 SVG 안의 실제 텍스트로.
- 화면 캡처(그림 1·2·3·5·6·8)는 교육용 계정으로 찍고 이름·이메일·프로필을 가린다. 캡처일을 등록부에 기록한다.
- 모든 이미지에 대체 텍스트. 도식은 같은 내용을 본문 목록으로도 제공한다.
