# Codex 가이드 — 선택 심화와 제작 활용

Codex는 **선택(OPTIONAL) 심화 도구**다. 과정의 핵심 목표는 Codex 없이 달성되어야 한다(CD-14). Codex의 제공 범위·접근 방법은 [AS-OF: codex-availability].

## 1. 교육과정에서의 위치
- 정규 14교시에 Codex 활동은 없다. core 교시의 목표·산출물·활동·카드에 Codex가 나오면 validator 오류다(V-CRS-009).
- `/optional/codex` 1페이지만 둔다(course.yaml `modules.optional-codex`). 페이지 첫 줄: "몰라도 수료에 지장 없습니다."
- 제작 순서상 가장 마지막 phase다.

## 2. 쓰는 경우와 쓰지 않는 경우
| 쓴다 (후보) | 쓰지 않는다 |
|---|---|
| 반복적인 파일 정리, 여러 문서 일괄 처리 | 일반적인 문서 요약 |
| 평가 결과 CSV 정리·집계 | 간단한 보고서 초안 |
| 간단한 데이터 변환 | 단순 분류 |
| 평가세트 반복 실행·채점 자동화 | ChatGPT만으로 충분한 작업 |
| 간단한 내부 업무 도구 | 코딩 때문에 난이도만 올라가는 경우 |

## 3. 선택 심화 페이지에 반드시 넣을 것
- 전제조건: 설치 필요 여부(데스크톱 앱·CLI·IDE), 기관 PC의 설치·보안 승인, 요금제별 사용량 한도 [AS-OF: codex-availability]
- 하네스 관점의 설명: Codex도 지침(AGENTS.md 등)·검증(테스트)·안전장치가 있어야 안정적으로 일한다
- 실습 데이터는 가상 자료만, 실제 업무 파일 금지
- 분류 I 카드만 사용(track: optional)

## 4. 콘텐츠 제작에서의 활용
- 이 저장소의 제작 실행자는 Claude Code(`scripts/execute.py`)다.
- Codex는 필요하면 대량 변환·가상 데이터 생성 같은 보조 작업에 쓸 수 있다. 결과는 **같은 AC와 validator를 통과해야** 하며, 별도의 검증 경로를 만들지 않는다.
- Codex로 만든 결과도 AI 산출물이므로 status는 draft까지다(ADR-005).
