# 도구 활용 가이드

도구를 **어떻게 가르칠지**를 정한다. 도구의 기능·한도·메뉴 위치는 [`content/product-features.yaml`](../content/product-features.yaml)에만 있고, 여기서는 `[AS-OF: id]`로 가리킨다. 도구 사용법 자체가 수업의 중심이 되지 않게 한다 — 도구는 ③ 도구 요소와 업무 흐름을 만들기 위한 수단이다.

## 1. 도구의 역할 분담
| 도구 | 역할 | 수업에서 |
|---|---|---|
| ChatGPT Project | ① 지침과 ② 근거를 담는 그릇, 여러 건 처리 | D1-3부터 [AS-OF: chatgpt-projects] |
| 구글 폼 | 업무의 입구 — 입력을 문항으로 구조화 | D2-1 |
| 구글 시트 | 대장 — 응답 축적, 분류 결과, 평가, 로그 | D1-2(하네스 대장)부터 |
| 구글 드라이브 | 템플릿 사본, 자료 보관 | 템플릿 사본 만들기 |
| Codex | 선택 확장 — 반복 파일 처리·검증 자동화 | 정규 교시 없음, [CODEX_GUIDE.md](CODEX_GUIDE.md) |

## 2. 붙여넣을 곳 3종 (초보자가 가장 많이 헷갈리는 부분)
| 붙여넣을 곳 | 무엇을 넣나 | 오래 남나 |
|---|---|---|
| **Project 지침란** | 지침서 5항목, 지침 조각 카드 | 그 Project의 모든 대화에 적용 |
| **Project 파일** | 근거 자료(법령 발췌, 교육용 FAQ) | Project에 계속 남음 [AS-OF: chatgpt-project-file-limit] |
| **채팅 입력창 / 첨부** | 이번에 처리할 입력 데이터(CSV), 요청 카드 | 그 대화에만 (첨부가 Project 파일이 되는지는 확인 전 [TBD: OQ-05]) |

입력 데이터(민원 CSV)는 Project 파일이 아니라 채팅 첨부로 넣는다(CD-07). 근거와 입력을 섞으면 ② 근거가 오염된다.

## 3. ChatGPT 수업 방식
- **Project 만들기(D1-3)**: 강사가 전체를 시연하고 수강생이 따라 한다. 지침은 반드시 지침란에 넣는다.
- **근거 연결(D1-4)**: 제공 zip 1개를 내려받아 올린다. 지침에 "올린 자료 안에서만, 출처(조문) 표시, 자료에 없으면 확인 필요" 규칙을 추가한다.
- **평가(D1-6)**: 답변은 Project의 새 대화에 질문만, 채점은 Project 밖 임시 채팅에서 한다. 절차는 [PRACTICE_DESIGN.md](PRACTICE_DESIGN.md) 3절(CD-17)을 따른다.
- **기준 답변(D1-1)**: 비개인화 임시 채팅을 쓴다 [AS-OF: chatgpt-temporary-chat].
- **데이터 제어(D2-4)**: 수강생이 직접 "모델 학습에 대화 사용"을 끈다 [AS-OF: chatgpt-data-controls-training].
- **동료 공유**: 프로젝트 공유로 안내한다 [AS-OF: chatgpt-project-sharing]. 맞춤형 GPT는 개인 Plus에서 새로 만들 수 없으므로 가르치지 않는다 [AS-OF: chatgpt-custom-gpt-creation].

## 4. 구글 폼·시트 수업 방식
- **폼 만들기(D2-1)**: 처음부터 만들기 → 문항 4~6개 → 미리보기 → 설정에서 이메일 수집 끄기 → 응답 시트 연결 → 시트 공유 범위를 부서 내부로.
- **데이터 모으기**: 수강생 폼은 만들기 연습용. 분석 데이터는 강사 공용 폼(역할카드 응답)과 제공 CSV(CD-19).
- **시트 → ChatGPT(D2-2)**: 시트를 표 파일(CSV)로 내려받아 Project 채팅에 첨부한다. 결과 표를 다시 시트에 붙여 대장으로 만든다.
- **제안서의 7단계 절차**(시트 범위 복사 → 입력창에 붙여넣기)는 **플랜 B**로 유지한다.

## 5. 알려진 실패와 플랜 B
| 상황 | 플랜 B | 관련 |
|---|---|---|
| 교육망에서 파일 업로드가 막힘 | 근거 자료 본문을 입력창에 붙여 넣는다(D1-4), 표는 복사해 붙인다(D2-2) | 제안서 운영 메모 |
| 결과 표를 시트에 붙이면 한 칸에 다 들어감 | 공통 카드 "표가 깨질 때" | `card-help-broken-table` |
| 출력이 중간에 끊기거나 너무 김 | 공통 카드 "출력이 끊기거나 너무 길 때", 문항을 나눠 실행 | `card-help-long-output` |
| 결과가 이상함 | 공통 카드 "결과가 이상할 때 원인 찾기"(지침·근거·입력) | `card-help-odd-result` |
| 사용량 한도 도달 | 강사 화면을 보며 따라가고, 다음 교시에 이어서 | [AS-OF: chatgpt-file-uploads] |
| Project를 쓸 수 없음 | 일반 대화 첫 메시지에 지침과 근거 발췌를 붙여 같은 대화 안에서 실습 | [AS-OF: chatgpt-projects] |
| Vercel 사이트 접속 불가 | 오프라인 번들 또는 강사 PC 로컬 실행(CD-05) | [DEPLOYMENT.md](DEPLOYMENT.md) |

## 6. 공통 문제 해결 카드 3종
모든 교시의 "잘 안 될 때"에서 같은 카드를 불러 쓴다. course.yaml `cards`의 `lesson: common`.
1. 결과가 이상할 때 원인 찾기 — 지침인지, 자료인지, 입력인지
2. 출력이 끊기거나 너무 길 때
3. 표가 깨질 때

## 7. 교육망·계정 준비 (개설 전)
- 교육망 예외 요청 도메인: 제안서의 ChatGPT·구글 도메인 목록 + 강의 사이트 도메인. 목록은 운영 체크리스트(Phase 7)에서 관리한다.
- 개설 4주 전 강의실 PC 접속 테스트(로그인, 파일 업로드, 폼 작성, 강의 사이트).
- 개설 1주 전 그림 안내문 발송: 개인 Plus 로그인, 구글 계정 로그인, 두 창 나란히 쓰는 법. 기관 계정은 차단될 수 있어 개인 계정을 권장한다.
