# PRD: 공무원을 위한 하네스 엔지니어링 — 웹 강의자료

## 목표
수강생이 "AI에게 질문을 잘하는 사람"이 아니라, **자신의 업무를 AI가 반복적으로 수행하도록 지침·근거·도구·검증·안전장치·기록으로 업무 환경을 설계하는 사람**이 되게 하는 2일 14시간 과정의 강의자료를 만든다.

이 저장소가 만드는 제품은 두 가지다.
1. **과정(커리큘럼)** — 교시 구조, 실습, 평가, 산출물. 수치는 [`content/course.yaml`](../content/course.yaml).
2. **웹 강의 사이트** — 강사가 화면에 띄우고 수강생이 자기 PC에서 동시에 따라가는 HTML 사이트.

## 사용자
| 사용자 | 필요 |
|---|---|
| 수강생 | 국가직·지방직 일반 행정 공무원, 개인 ChatGPT Plus 사용자(CD-01), 비개발자, 생성형 AI 초보 포함. 막히면 스스로 AI에게 도움받을 수 있어야 한다 |
| 강사 | 화면에 띄워 설명하기 쉬운 교시 페이지, 시연 순서, 시간 부족 시 생략 항목 |
| 보조강사 | 수강생 계정·도구 문제 해결 절차 [TBD: OQ-18] |
| 자료 관리자(강사 본인) | Markdown 수정, GitHub 웹 편집, 자동 검증, 개설 차수별 갱신 |

## 핵심 기능
1. 교시 페이지(2일 × 7교시) — 유형별 템플릿, 필수 경로, 실습 3단(함께 하기 / AI 도움받기 / 내 업무 적용)
2. AI에게 도움받기 카드 — 막힘 지점에만 배치, 복사 버튼, 3단계(따라 쓰기/바꿔 쓰기/직접 쓰기) 펼침
3. 프롬프트 라이브러리(`/prompts`) — 실제 사용 카드만 분류·교시별로 모음
4. 실습 키트·템플릿 — 하네스 대장, 지침서, 평가세트, 설계서, 점검표, 가상 데이터
5. 교시 이동 — 이전/다음, 현재 Day·교시 표시, 진행 체크(브라우저 저장, 초기화 가능)
6. 오프라인 번들 — Vercel 접속이 막힌 교육장에서 브라우저로 직접 열기(CD-05)

## 범위 제외
- 서버, 데이터베이스, 로그인, 분석 도구, 쿠키
- 정규 교시에서 Codex 실습(선택 심화 1페이지만, CD-14)
- 맞춤형 GPT 제작 실습 — 개인 Plus에서 새로 만들 수 없음 [AS-OF: chatgpt-custom-gpt-creation]
- 실제 기관 문서·실제 민원 데이터 사용
- 강사 민감 메모(예상 질문 답, 운영 내부 메모)의 저장소 보관(CD-02)
