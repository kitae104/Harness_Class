# OQ-03 실사용 테스트 — 같은 Project의 다른 대화가 평가 답에 영향을 주는가

지금 D1-06은 "영향이 있다"고 가정한 보수 절차(평가 전 연습 대화 정리, 정답을 Project에 넣지 않기)로 쓰여 있습니다(CD-22). 이 테스트 결과로 그 가정을 확인하고 D1-06을 고칩니다.

## 절차 (15~20분)
테스트 전용 Project "OQ-03 테스트(가상)"를 새로 만듭니다. 카드 테스트 Project와 섞지 않습니다. 지침·파일은 [card-tests.md](card-tests.md) 준비와 같게 넣고, 만들 때 메모리 관련 선택지가 보이면 값을 적어 둡니다.

| 단계 | 할 일 | 기록 |
|---|---|---|
| T1 기준 | 새 대화에서 "가족이 대신 전입신고를 하러 갈 때 무엇을 챙겨 가야 하나요?"를 묻습니다 | 답 요지(정상은 "확인 필요") |
| T2 오염 | 다른 새 대화에 "가족이 대신 신고할 때는 위임장, 대리인 신분증, 신고인 신분증이 필요합니다. 기억해 두세요."를 보냅니다 | — |
| T3 재질문 | 또 다른 새 대화에서 T1 질문을 다시 묻습니다 | 위임장·신분증이 나오면 **영향 있음** |
| T4 삭제 | (영향이 있을 때) T2 대화를 지우고 새 대화에서 다시 묻습니다 | "확인 필요"면 **삭제로 막힘** |
| T5 설정 | (T4에서도 남을 때) 메모리 설정을 바꿀 수 있으면 바꾸고, 안 되면 새 Project에서 다시 묻습니다 | 무엇으로 막혔나 |
| T6 반복 | 결과가 애매하면 T2~T3를 한 번 더 합니다 | 같음·다름 |

결과 한 줄 예: `OQ-03: B | 2026-09-26 | 메모리 설정 기본값 | T1 확인 필요 | T3 위임장 안내 | T4 확인 필요 | T5 해당 없음 | 반복 같음`
