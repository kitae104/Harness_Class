이 프로젝트의 변경 사항을 리뷰하라. 이 리뷰는 **보고용**이며 통과 관문이 아니다. 통과 여부는 AC(`npm run verify`)와 사람의 `review:approve`가 결정한다.

먼저 다음 문서들을 읽어라:
- `/CLAUDE.md`
- `/docs/ARCHITECTURE.md`
- `/docs/ADR.md`
- `/docs/CONTENT_GUIDE.md`
- `/docs/QUALITY.md` (규칙 ID 목록)

그런 다음 변경된 파일들을 확인하고, 아래 체크리스트로 검증하라:

## 체크리스트 — 구조

1. **아키텍처 준수**: ARCHITECTURE.md에 정의된 디렉토리 구조와 파일→URL 규칙을 따르는가?
2. **기술 스택 준수**: ADR에 정의된 기술 선택을 벗어나지 않았는가?
3. **테스트 존재**: 새 코드(컴포넌트, 스크립트)에 대한 테스트가 있는가?
4. **CRITICAL 규칙**: CLAUDE.md의 CRITICAL 규칙을 위반하지 않았는가?
5. **빌드 가능**: `npm run verify`(Phase 1 이전에는 `python -m pytest scripts -q`)가 통과하는가?

## 체크리스트 — 교육 콘텐츠

6. **단일 원천**: 시간·교시 수·제품 기능·법령 조문·외부 링크를 본문에 직접 쓰지 않고 등록부 ID로 참조했는가?
7. **학습 연결**: 학습목표 → 실습 → 산출물 → 결과 확인이 이어지는가? 다음 교시에 필요한 산출물이 만들어지는가?
8. **6요소**: 이 교시가 담당하는 Harness 요소가 course.yaml과 일치하는가?
9. **초보자 지원**: 카드가 막힘 지점(stuck_point)에만 있는가? 실습형 교시에 예상 결과와 잘못된 결과 예시가 있는가? 수강생 화면에 개발 용어가 없는가?
10. **CORE / OPTIONAL**: core 콘텐츠가 Codex나 optional 콘텐츠를 선행 조건으로 요구하지 않는가?
11. **개인정보·보안**: 실제 개인정보, 실제 기관 문서, 비공개 원본이 없는가? 가상 자료에 "가상" 표기가 있는가? 캡처의 계정 정보가 가려져 있는가?
12. **정보 상태**: 확인되지 않은 내용에 `[PROVISIONAL]`, `[TBD: OQ-xx]`, `[AS-OF: ...]` 태그가 있는가?
13. **검토 상태**: AI가 콘텐츠 status를 `reviewed`로 올리지 않았는가? reviewed 콘텐츠를 수정했다면 재검토가 필요하다고 표시했는가?
